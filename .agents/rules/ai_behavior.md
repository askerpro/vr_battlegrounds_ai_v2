# Поведение ИИ и Обязательные Алгоритмы

## 🚦 ОБЯЗАТЕЛЬНЫЙ ПОРЯДОК РАБОТЫ ДЛЯ ИИ-ПОМОЩНИКА
> Это главное правило. Нарушение приводит к лишней работе.

### Шаг 0 — Перед любой задачей: читать документацию
Прежде чем лезть в код или отвечать на вопрос:
1. Прочитать `Docs/README.md`
2. Прочитать `Docs/UltimateXR/known-issues.md`
3. Прочитать `Docs/UltimateXR/architecture.md`
Исключения: синтаксические правки, изменение уже открытых док, изолированные вопросы.

### Оптимизация слеш-команд (Воркфлоу)
- Папка с пользовательскими воркфлоу жестко задана: `_agent/workflows/`.
- ❌ **ЗАПРЕЩАЕТСЯ** использовать инструменты поиска файлов (`find_by_name`, `list_dir`) для нахождения файлов воркфлоу.
- ✅ При получении команды, вызывайте `view_file` для чтения `_agent/workflows/<команда>.md`.

## Стиль общения и поведение
- **Уточнять контекст реализации по запросу** — предлагать варианты, спрашивать про интеграцию.
- **Ответы содержат несколько слоёв** — Зачем (почему так), Риски (проблемы), Альтернативы (варианты).
- Оставлять краткие пояснения в комментариях, таблицы для структуры ресурсов.
