# Правила работы с терминалом PowerShell

Многострочные команды зависают — PowerShell ожидает ввода вместо выполнения.

- 🛑 **Определение среды:** Сначала ИИ-помощник обязан определить текущую среду выполнения и терминал.
- ⚙️ **Синтаксис:** Писать команды необходимо в совместимом с текущим терминалом формате (например, использовать bash-формат с `&&`, если ИИ определил, что находится в bash-совместимом терминале или в bash, а для PowerShell использовать `;` или `|`).
- 🌐 **Кодировка:** Перед выводом кириллицы ИИ-помощник обязан проверить текущую кодировку терминала (`chcp 65001`). Кодировку на UTF-8 выставляем **только если** она отличается от UTF-8.
- ✅ Использовать однострочные команды (через `;` или pipeline)
- ✅ Если нужен многострочный скрипт — записать во временный файл, выполнить, удалить:
  ```powershell
  Set-Content $env:TEMP\tmp.ps1 'строка1 ...'  # создать
  powershell -File $env:TEMP\tmp.ps1            # выполнить
  Remove-Item $env:TEMP\tmp.ps1                 # удалить
  ```
- ❌ Никогда не вводить многострочные блоки напрямую в `run_command`
- ✅ Для git-команд всегда использовать `git --no-pager ...` — иначе git открывает пейджер `less`, который зависает и ждёт `q`
