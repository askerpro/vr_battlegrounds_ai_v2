# Память эксперта по манипуляциям

Уроки процесса и предпочтения пользователя. Архитектура и решения — в `tasks/haptics-system/expert/`, не здесь.

- Пользователь проверяет механику сам в шлеме через Quest Link на worker: займи аренду, включи Play Mode, дай
  чек-лист по пунктам; пока он смотрит, продлевай аренду (`renew` каждые ~5 мин фоновым циклом с файлом-стопом).
  Закончил — Play выкл, `finish`, `receive` до любых правок.
- Аренда брокера: ждать OFFERED на переднем плане (`watch-ticket --until offered --timeout 580`, цикл); после
  `claim`/`begin` выполнить весь пакет и `finish` в том же ходе. Истёкшая аренда блокирует очередь всем агентам.
- Ключ `request --key` уникален навсегда: повтор с другим содержимым — отказ «ключ уже закреплён».
- Пока у этапа нет `begin`, хук пускает только простые команды координации без пайпов, `$(...)` и циклов; полный SHA
  — отдельной командой `git rev-parse HEAD`. После `verify` допуск этапа закрыт.
- Пересечение `writes` даже с запланированным чужим этапом — `begin` отвечает `UNORDERED_OVERLAP`; просить владельцев
  добавить `after` через `message`, ответы читать `inbox --event <id>`.
- Unity MCP иногда теряет `run_tests`/`execute_code` из клиента — вызывать через `batch_execute`
  (`{"tool":"run_tests","params":{...}}`); `execute_code` — `compiler: codedom`; Android — `AndroidCompileGate.Run().Summary`.
- Тест падения компиляции на worker: `begin` вернёт «ошибки компиляции» и тикет уйдёт в RECOVERY_REQUIRED — сразу
  `recover`, затем текст ошибок из `%LOCALAPPDATA%/Unity/Editor/Editor.log` (`error CS`).
- Генерация текста через Python heredoc: `"\\n"` в C#-строке превращается в настоящий перевод строки — проверять.
  Не начинать bash-команду с `cat > файл` без heredoc — зависнет на stdin.
- Пользователь предпочитает рекомендацию с ценой, а не перечень; короткие ответы; правку чужих префабов — через
  значения по умолчанию, а не массовые миграции.
