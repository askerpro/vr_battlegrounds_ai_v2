# Правила проекта — см. CLAUDE.md

Единственный источник правды для ИИ-агентов — файл `CLAUDE.md` в корне репозитория. Прочитай его и следуй ему.
Углублённые правила по зонам — в `.agents/rules/`.

**Редактор Unity общий** — над проектом одновременно работают несколько агентов и человек. Перекомпиляция, тесты,
Play Mode и открытие сцен — только под замком `Tools/agents/unity-lock.sh`; правила — `.agents/rules/unity_sharing.md`.
