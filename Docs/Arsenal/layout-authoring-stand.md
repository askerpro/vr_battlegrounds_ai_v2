# Стенд раскладки слота

| Цель | Мы здесь | Осталось | Технический документ |
|---|---|---|---|
| Человек размещает оружие, магазин, карточку, опоры и коробку приёма и сохраняет их в раскладку слота | Стенд пишет в ассеты `ArsenalSlotLayout`; генератор применяет их на всех картах (принято 2026-10-09). С 2026-10-20 стенд работает только с одним выбранным стволом (задача `weapon-sight-calibration`) | Художественная донастройка поз по стволам | Этот документ |

Позы слота хранит ассет «Раскладка слота» (`ArsenalSlotLayout`, `Assets/Data/Arsenal/SlotLayouts/`): вид слота,
позы оружия, магазина и карточки, размер и шрифт карточки, опоры, коробка приёма. Префаб слота держит раскладку по
умолчанию (`Default_Pegboard`, `Default_Shelf`); `WeaponInfo` может принести свою раскладку для вида слота (не больше
одной на вид). Одну раскладку могут разделять несколько стволов — правка ассета меняет их все.

## Один ствол на стенде

Решение пользователя 2026-10-20: у стенда один режим — раскладка конкретного оружия; общего стенда со всем
ассортиментом пресета нет.

- **Вход** — окно `Tools/VR Battlegrounds/Weapons/Настройка оружия`, вкладка «Раскладка в слоте»: показывает свои
  раскладки ствола и где они используются, кнопка «Открыть стенд раскладки с этим оружием» (у ствола, который стоит
  в рядах разных видов, — по кнопке на каждый вид слота). Пустой стенд в Inspector ведёт в то же окно.
- **Вид слота** выводится из рядов, в которых ствол стоит во всех пресетах проекта (ключ ряда → вид по корпусу
  лобби); если ствола нет ни в одном пресете — из видов его собственных раскладок. Иначе вид неизвестен — окно
  сообщает об этом.
- **Сцена** `Assets/Scenes/Debug/ArsenalLayoutAuthoring.unity` хранится пустой: carrier `ArsenalLayoutAuthoringStand`
  (владелец, стиль, один слот: оружие, вид, ручки, отпечатки), свет, камера. Слот — временная проекция
  (`DontSaveInEditor`), в сцену не пишется; сцена не входит в Build Settings и не является входом генератора.
  В проекции нет SDK, NetworkIdentity, физики и игровых контроллеров. Сохранение сцены с открытым стволом даёт
  небольшой diff (ссылка на оружие, вид, отпечатки) — сохранять её не нужно.

## Маршрут

1. «Настройка оружия» → выбрать оружие → «Раскладка в слоте» → «Открыть стенд раскладки…». Стенд строит слот этого
   ствола из действующей раскладки и выделяет корень стенда; Scene View кадрирует слот.
2. Inspector стенда показывает действующую раскладку и какие стволы её используют.
3. Кнопками «Выбрать: Оружие / Магазин / Карточка / Коробка приёма» или «Выбрать опору» выделить ручку и двигать её
   обычными Move/Rotate. Размер коробки приёма — размер её BoxCollider (Edit Collider; Scale не используется).
4. «Запечь → действующая раскладка» пишет позы в действующий ассет раскладки. Позы, совпадающие с сохранёнными
   (до 1e-6 м и 0,001°), не переписываются — Bake без сдвигов отвечает «нет изменений». Сохранение сцены само по
   себе позы не запекает. Если раскладку разделяют несколько стволов, стенд об этом предупреждает.
5. «Отдельная раскладка для этого ствола» копирует действующую раскладку в
   `Assets/Data/Arsenal/SlotLayouts/<WeaponId>_<вид>.asset` и назначает её оружию — правка больше не затронет других.
6. «Восстановить из раскладки» пересобирает слот из сохранённого ассета.

Подтверждение пересборки спрашивается только при незапечённых позах текущего исправного слота (при открытии другого
ствола или Restore). Пустой или устаревший слот (утрачена ручка, отпечаток не совпал) пересобирается без вопроса.

Масштаб ручек запрещён: физический размер оружия и магазинов сохраняется. Генератор применяет раскладки как есть
и не проверяет, влезает ли оружие ([принцип](generator-foundation.md#принцип-применять-не-проверять)).

## API (`Assets/Editor/VR_Battlegrounds/Arsenal/ArsenalLayoutAuthoringStandEditor.cs`)

| Метод | Что делает |
|---|---|
| `PopulatePrepared(scene, style)` | Первичная сборка carrier в сцене стенда (под внешней агентской арендой) |
| `KindsOf(weapon)` | Виды слота ствола по пресетам проекта или его раскладкам |
| `OpenPrepared(stand, weapon, kind, discardStaged)` | Строит слот выбранного ствола и вида |
| `RestorePrepared(stand, discardStaged)` | Пересобирает текущий слот из раскладки |
| `ClearPrepared(stand)` | Пустой стенд |
| `BakePrepared(stand)` | Запекает ручки единственного слота в действующую раскладку |
| `SeparateLayoutPrepared(stand)` | «Отдельная раскладка» для ствола слота |
| `ConfirmRebuild(stand, action)` | Диалог при незапечённых позах |

Запись идёт под арендой `ArsenalEditorActions.AcquireAuthoringLease`. Прежние «Запечь все», выбор слота из списка и
проекция по `Preset.Entries` удалены 2026-10-20 вместе с пробами старого общего стенда
(`Tools/Probes/arsenal-authoring-*`, остались в истории Git).

## Коробка приёма

`ArsenalAnchorPlaceZone` на якоре оружия заменяет сферу приёма коробкой: сфера якоря UltimateXR расширяется до
дальнего угла коробки, штатный валидатор пропускает предмет только когда его точка приёма внутри коробки. Коробка
задана в координатах слота и двигается вместе с ним. Правка SDK не нужна. Раскладка без коробки (нулевой размер)
оставляет сферу якоря как есть.
