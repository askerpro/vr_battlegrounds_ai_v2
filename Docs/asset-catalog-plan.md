# Каталог декоративных замен: первый проход

Цель: получить измеренные кандидаты Industrial Set для 18 блоков LD_Alphabet,
изображения и таблицу рецептов для визуальной проверки пользователем.
Пользователь поручил начать после обсуждения подхода; выполняем в этой сессии.

## Ограничения

- Игровой проект и общий редактор не импортируют пак и не меняют сцену.
- Отдельный проект: `Temp/LevelDesign/IndustrialCatalog`, Unity 6000.4.1f1.
- Исходники инструментов: `Tools/AssetCatalog/`; editor-файлы в отдельном проекте
  размещаются только под `Assets/Editor/VR_Battlegrounds/LevelDesign/`.
- Предварительные соответствия не утверждают сохранение игровой механики.
- Равномерный масштаб 0.8–1.5; увеличение более 20% отмечается отдельно;
  поворот вокруг Y 0/90 градусов;
  простые ряды/штабели до четырёх одинаковых предметов.
- До проверки пользователем новые игровые тесты не пишутся.

## Шаги

1. Безопасно извлечь модели, префабы, материалы и текстуры, сохранив GUID.
   Исключить сцены, скрипты, ProjectSettings и вложенные пакеты.
2. Измерить реальные меши с трансформами префабов; отдельно сохранить LOD,
   материалы, коллайдеры, ошибки импорта. Снять виды моделей.
3. Сопоставить одиночные объекты и ограниченные сборки с геометрией эталонов.
   Габариты и силуэт — предварительный фильтр, не доказательство эквивалентности.
4. Сохранить JSON, таблицу и изображения; проверить полноту и просмотреть
   примеры. Зафиксировать ограничения и команды повторного запуска.

Следующий этап — принятые рецепты и стенд для проверки в шлеме. Полный импорт
всех паков и перенос в игровой проект не входят в этот первый проход.

После первого прохода пользователь разрешил импортировать все 13 паков
окружения в игровой проект. Этот следующий этап описан отдельно в
[environment-pack-import.md](environment-pack-import.md); ограничения
изолированного проекта выше относятся к первоначальному каталогу Industrial.

Уточнение по результатам измерений: кубический ящик пака имеет сторону около
0.81 м, эталон LD_Crate — 1.2 м. Для первого каталога допускаем равномерное
увеличение до 1.5, без растягивания по отдельным осям; увеличенные объекты
помечаются для проверки пользователем. Повтор электрических шкафов в глубину
и подмена цилиндров прямоугольными шкафами исключены после визуального ревью.
