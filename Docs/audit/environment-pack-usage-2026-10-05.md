## Метод и воспроизводимость

Одноразовый исследовательский скрипт: `tmp/environment-pack-audit/probe_usage.py`. Он индексирует GUID текущих `.meta`, ищет GUID-подобные токены и точные строки путей, строит граф и транзитивные цепочки от внешних корней. `.meta` анализируются отдельно, включая remap импортера. Дубликаты экземпляров и повторные ссылки не увеличивают число сохраняемых файлов.

Команды:

```powershell
python -X utf8 tmp/environment-pack-audit/test_probe.py
python -X utf8 tmp/environment-pack-audit/probe_usage.py --output tmp/environment-pack-audit/report
```

Контрольный набор: **PASS**, один тест с проверками циклического графа, зависимости только из importer `.meta`, точного пути JSON-рецепта, отдельного основания review, неизвестного бинарного ассета, отсутствия ссылки и неизменности исходных файлов.

Фактический проход: **93,67 с**, 15 680 прочитанных входов, 2472 внешних ребра к файлам паков. Не обнаружены конфликты GUID и осиротевшие/невалидные `.meta` среди индексируемых записей. Файлы без `.meta` этот probe полноценно не выявляет. Для каждого прочитанного входа сравнивались размер/mtime до и после чтения; изменений во время отдельного чтения не обнаружено. Это не атомарный снимок всего общего workspace.

Fingerprint прочитанных входов: `4dc0bb7204485552305351f7ce9548cd5db1d32d81eab554c719548ab0a39a25`.

## Неопределённости перед очисткой

- **11 бинарных сериализованных входов** не разобраны: TerrainData/LightingData паков, LightingData стенда и `Assets/Scenes/Maps/TestMap2/LightingData.asset`. Последний относится к собственной карте и особенно важен для Unity-сверки. Их зависимости способны расширить набор сохранения.
- **7213 файлов SDK** исключены из анализа содержимого; их `.meta` использованы для разрешения GUID. Отсутствие ссылок из SDK не доказано.
- **29 неподтверждённых строковых указаний** на паки: корни поиска, динамически собираемые пути и подписи объектов стенда. Это не 29 битых ссылок: часть строк вообще не является путём отдельного ассета.
- GUID-подобные токены дают консервативные совпадения; семантика ссылок Unity не восстановлена полностью. Полный проход Addressables/`Resources.Load`/динамических загрузок не выполнен.
- Временные `Temp/LevelDesign/EnvironmentImport` и `Temp/EnvironmentRelocation` отсутствуют. Старые манифесты переназначения GUID недоступны; первая копия каталога должна строиться из текущего установленного состояния.
- Метрики файлового аудита не определяют размер сборки и экономию `Library`.

## Подготовленное решение

[Контракт каталога](../level-design/environment-pack-policy.md) и [план реализации](../plans/2026-10-05-environment-pack-separation.md) задают последовательность: постоянный файловый аудит → Unity-сверка → проверенная полная копия каталога → внешний поиск по экспорту → очистка игры по манифесту.

Подготовка выполнена; постоянный инструмент, второй проект Unity, сверка бинарных зависимостей и сама миграция ещё не выполнены. Пакеты, сцены, настройки Unity и игровой код этой подготовкой не изменены.
