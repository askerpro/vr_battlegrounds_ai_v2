# Анимация ног аватаров: native UXR

Цель: ноги шагают клипами (стойки без оружия / пистолет / винтовка, ход, повороты на месте) и не мешают
верхней части тела UltimateXR. Сидения, приседа, колена на полу, оценки таза игрока и наклонов корпуса нет —
упрощение 2026-10-06: все эти механизмы конфликтовали с BodyIK (руки уезжали, корпус и колено прокручивались,
ход выключался), а ходьба на клипах работала до их появления. Механика требует проверки человеком в шлеме.

## Владение позой

Верхнюю часть тела ведёт UltimateXR без изменений под ноги: `UxrBodyIK` — таз, позвоночник, шея, голова;
`UxrArmIKSolver` — руки. Ноги ничего в корпусе не меняют и пишут только кости от бедра вниз.
`AvatarStanceFromGrabs` задаёт только стойку (`Legs_Stance`: 0 без оружия, 1 пистолет, 2 винтовка). Сейчас
основной и единственный используемый набор — **винтовка**: она стойка по умолчанию (`DefaultStance`, значение
параметра в контроллере), выбор по оружию в руках сохранён, но выключен (`AvatarStanceFromGrabs.SelectByGrabs = false`).

`UxrAnimatedLegs` содержит отдельную невидимую humanoid-копию скелета с Animator. Порядок кадра:
Animator копии играет клип, root motion копится в `UxrLegRootMotionReceiver`; в стадии PostProcess
UltimateXR решает тело, затем ноги: root motion двигает корень копии по горизонтали и рысканью, позы стоп
копии с посадкой подошвы на пол становятся целями `UxrLegIKSolver`, `UxrLegLocomotion` решает шаг и
пишет параметры клипов на следующий кадр. Решение «идёт ли игрок» принимает `UxrBodyMotion` по позиции
камеры (вход), а не по опоре тела или корню копии (выходы решателей).

Если кто-то вне BodyIK двигает предков запястий (таз, корень рига), это делается только внутри
`using (controller.KeepTrackedBones())` — иначе руки уезжают вместе с телом
([SDK patch 46](UltimateXR/sdk-patches.md#патч-46-сдвиг-предков-запястий-вне-bodyik-сохраняет-позы-рук)).
Сейчас ноги таких сдвигов не делают.

Контроллер `AvatarLegs_Locomotion`: состояния `Legs_Idle` (покой и повороты на месте по `Legs_Turn`, без
Foot IK) и `Legs_Move` (Freeform Directional по `Legs_MoveX/MoveZ` с покоем в центре, Foot IK), поддерево
каждого — по `Legs_Stance`. Переходы `Idle ↔ Move` по `Legs_IsMoving`, 0,2 с, **без прерываний**: переход,
прерываемый собственным постоянно истинным условием, замораживает Animator (известная проблема переноса
T-42, [Issue 31](UltimateXR/known-issues.md#issue-31-ноги-скользят-по-полу-вместо-шагов-ноги-t-42)).

## Сборка и границы миграции

`Tools/VR Battlegrounds/Avatars/Setup Legs` пересобирает контроллер, маску и копии скелетов текущих
владельцев тела MEF / Heavy / Cyborg. Текущие prefab GUID сохраняются. У вариантов снимаются
только переопределения native legs, rig/controller и высоты лодыжки; карманы, оружие, режим IK рук и
калибровка не сбрасываются. Удаляются только известные старые компоненты ног. Произвольные missing
scripts на игровых префабах не очищаются.

Старые `LegsAnimatorUxrBridge` / `LegsGrounding` пока сохранены как типы для компиляции старых
тестов; одновременно с native legs на мигрированных аватарах они не должны работать.
Старые ожидания `AvatarLoadoutTests`, `PrefabCompositionTests` и grounding перечислены в
[T-42](tasks/T-42-uxrlegs-seated-port.md); они обновляются после принятия механики по AGENTS.md.

## Стенд

`Tools/VR Battlegrounds/Debug/Avatar Puppet Stand` собирает сцену стенда-кукловода с двумя MEF:
ноги UltimateXR на клипах Mixamo и эталон VRIK (Final IK) на родных клипах
(`Prefabs/Player/Experimental/Optimized_MEF_Player_VRIK`, `AvatarVrikDriver`). Запуск —
`Avatar Puppet Stand Play`: стенд запрашивает свою сцену как временную стартовую у
`PlayModeStartFromOffline` и снимает запрос при возврате в Edit Mode.
