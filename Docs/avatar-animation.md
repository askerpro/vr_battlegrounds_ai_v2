# Анимация ног аватаров: native UXR

Цель: ходьба из клипов и обычное сидение без оборотов позвоночника и коленей.
Перенос интегрирован из `wip/uxrlegs-final`; присед с упором на колено отложен.
Текущий срез требует принятия человеком в Unity/шлеме; компиляция этого не подтверждает.

## Владение позой

`UxrStandardAvatarController` вызывает штатный BodyIK, готовит текущую позу `UxrAnimatedLegs`,
согласует таз через `UxrBodyIK.ApplySeatedPelvis`, затем решает ноги и руки. BodyIK — автор таза
и позвоночника. `AvatarStanceFromGrabs` задаёт только стойку 0/1/2 по оружию.

`UxrAnimatedLegs` содержит отдельную невидимую humanoid-копию текущего скелета с Animator.
Root motion и коррекции размещения завершаются до фиксации позы: мировые таз/корень ног,
стопы/колени, локальные кости и **оценённый** `Legs_Sit` сохраняются вместе. Параметры,
записанные затем, относятся к следующей оценке Animator. Ноги не читают позднее перемещённый риг.

Отдельный корень ног перед BodyIK возвращается в локальную позу префаба. Частичное владение
каждый кадр смешивается от этой базы, поэтому не накапливает поворот предыдущего решения.
Выключение владельца инвалидирует snapshot, возвращает кости в покой и сбрасывает root motion
и историю плоскостей; поздний `AfterSolve` не возвращает старую сидячую позу.

`Legs_Sit`: 0 — стоя, 1 — обычное сидение. Наличие клипа сидения измеряется по каждой стойке,
независимо от `hasKneelPose`; текущий контроллер оставляет `Legs_Crouch` равным нулю.
Высота tracked neck выбирает переход с гистерезисом и сглаживанием. Привязки к стулу/контакту сиденья нет.

Сидячие клипы есть только в `Legs_Idle`, где Animator Foot IK выключен. `Legs_Move` содержит
только стоячую ходьбу с Foot IK. Посадка немедленно переводит Animator в Idle, включая прерывание
уже начавшихся переходов start/stop. Обычный start/stop сохраняет переход 0,2 с.

Штатные доли head bend продолжают складываться child→parent. Общий trunk применяется один раз
на нижнем позвоночнике. Сидячий constraint сохраняет высоту таза клипа и допускает согласованное
смещение **всей** нижней позы по XZ, чтобы корпус достиг шеи без изменения длины шейного сегмента.
Если ограниченный наклон не достигает шеи с погрешностью 3 мм на единичном масштабе,
constraint отклоняется, копирование таза/ног выключается на этот кадр и остаток попадает в диагностику.
Это предел решения, а не подтверждённая обработка любой глубины посадки.

При полном владении клипом IK ног не вызывается. В переходе аналитический `UxrLegIKSolver`
сбрасывает локальные позиции отдельно от поворотов текущего клипа; у проходов стопы и носка
разная история плоскости. Достоверность bend goal зависит от отклонения относительно длины ноги,
а не от абсолютного cross-product. Подписанные углы не скачут на границе ±180°.

## Сборка и границы миграции

`Tools/VR Battlegrounds/Avatars/Setup Legs` пересобирает контроллер, маску и копии скелетов текущих
владельцев тела MEF / Heavy / Cyborg. Текущие prefab GUID сохраняются. У вариантов снимаются
только переопределения native legs, rig/controller, признака kneeling и высоты лодыжки;
карманы, оружие, режим IK рук и калибровка не сбрасываются. Удаляются только известные старые
компоненты ног. Произвольные missing scripts на игровых префабах не очищаются.

Старые `LegsAnimatorUxrBridge` / `LegsGrounding` пока сохранены как типы для компиляции старых
тестов; одновременно с native legs на мигрированных аватарах они не должны работать.
Старые ожидания `AvatarLoadoutTests`, `PrefabCompositionTests` и grounding перечислены в
[T-42](tasks/T-42-uxrlegs-seated-port.md); они обновляются после принятия механики по AGENTS.md.

Независимый исходный [аудит](audit/uxrlegs-seated-code-audit-2026-10-03.md) содержит численные
контрпримеры прежних формул. Автономные проверки и ручной checklist фиксируются в T-42.
