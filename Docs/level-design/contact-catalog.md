# Локальная оценка композиций

Дополнительный инструмент калибровки, а не обязательный этап создания карты.
Оценка изолированной композиции не сохраняет баланс после переноса на полную карту:
там требуется заново измерять контакты и воздействие на пути.
Основной поток — [создание карты](level-design-workflow.md).

## Что реализовано

Меню `Tools/VR Battlegrounds/Level Design/Contact Catalog Review` открывает
ContactCatalogReviewWindow. Доступны список префабов, открытие Prefab Mode,
Draft/Accepted/Rejected для композиции, оценки позиций 1–5, заметки,
собственные критерии и измерения P→Q через ContactCatalogMeasurement.
Ноль означает «не оценено»; общего суммарного score нет.

ContactCatalogReviews хранит данные в
`Tools/LevelDesign/ContactCatalog/reviews.json`.
Идентификатор — GUID префаба; hash зависимостей определяет версию геометрии.
После изменения требуется повторное подтверждение; сохранение заметки
само по себе не делает оценку актуальной.

Критерии: защита от основной угрозы, обзор/контроль, манёвр/отход,
контр-игра, интерес игры. Измерение использует изолированную preview scene,
реальные маркеры Positions и существующий PositionImpactAnalysis.
Подготовленные допустимые позы обязательны; инструмент не выводит их из случайных блоков.

## Остаток

Код окна существует; постоянный набор эталонных префабов и сцена ContactCatalogLab
ещё не созданы. Пользовательский каталог оценок не сформирован.
Принятие UI и поведения требует человеческого ревью.
Этот инструмент не является готовой VR-сессией с аватарами и матчем
и не заменяет оценку [всей карты](map-evaluation.md).
