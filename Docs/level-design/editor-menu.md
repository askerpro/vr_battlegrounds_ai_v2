# Меню редактора карт

Общий корень — `Tools/VR Battlegrounds/Level Design`.
Блокинг открывается одной командой «Редактор блокаута». Построение, сетка,
настройки размеров, проверки и обслуживание доступны внутри этого окна.

| Раздел | Команды | Назначение |
|---|---|---|
| Редактор блокаута: строительство | Палитра, сетка, привязка | Построение геометрии активной карты |
| Редактор блокаута: настройки | Шаг, модуль и общий паспорт размеров | Одна строка на форму; изменение распространяется на варианты той же геометрии |
| Редактор блокаута: проверки | Принципы карты; влияние позиций; оценка контактной композиции | Явный выбор активной/всех боевых карт, JSON и префаба; результаты внутри окна |
| Art Pass/Decorate | Candidates/LEGO Marking; Candidates/Auto Mark Pack; Build Industrial Candidate Review; Demos/Show Selected Demo; Demos/Next Demo; Texture LD Blocks | Подбор кандидатов, просмотр композиции исходных паков и материалы эталонов |
| Art Pass/Check | Map Principles Report; Position Impact Report (Active Scene); Contact Catalog Review | Те же измерители после художественной замены |
| Редактор блокаута: обслуживание | Реестр, нормализация, миграция размеров и исторические рецепты | Явные операции с общими ассетами; область и последствия указаны перед кнопкой |

Проверки внутри редактора и команды Art Pass/Check вызывают одну реализацию каждого измерителя.
Смена пункта меню не меняет алгоритмы измерения и не превращает ручное одобрение
контактов в измеренный результат. Position Impact Report принимает собственный JSON
разметки активной сцены; смысловая кисть Scene Painter не подключает его автоматически.

Контекстное меню `GameObject/VR Battlegrounds/LEGO Candidate` остаётся рядом
с выбранным объектом. Демо-команды используются маркировкой кандидатов и галереей
IndustrialCandidateReview, поэтому доступны в Art Pass/Decorate/Demos.

Дополнительных пунктов меню для настроек, проверок блокинга и обслуживания нет.
Пути меню проверены в Assets/Editor и Assets/Tests: вызовов ExecuteMenuItem в этих
каталогах нет. Каталог Assets/Scripts/Tests отсутствует; тесты проекта находятся
в Assets/Tests. Перенос меню не добавляет и не переписывает тесты геометрии.

Геометрические подписи палитры хранятся в displayName и description определения.
BlockoutDefinitionText.FillMissing заполняет только пустые поля; заданный пользователем
текст сохраняется. Технические title, shapeId и dimensionsSourceKey остаются ключами
реестра и миграции. Описание предназначено для выбранной формы, а не каждой плитки.

BlockoutWorkspacePanel.DrawSettings/DrawChecks/DrawMaintenance встраиваются в окно
редактора. Настройки используют прежние Save/BlockoutAlphabetGridMigration,
а проверки — MapPrinciplesReport, PositionImpactReport и общую отрисовку каталога
контактов. Кнопки обслуживания вызывают исходные рецепты без повторения реализации.
Применение паспорта и исторические рецепты меняют общие префабы для всех карт;
исторические рецепты могут перезаписать пользовательские правки эталонных ассетов.
