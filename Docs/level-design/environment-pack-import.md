# Импорт паков окружения

Пользователь 2026-10-02 поручил импортировать все 13 найденных архивов окружения
из кеша Asset Store в игровой проект, вместо дальнейшей работы только в
отдельном проекте каталога. Исходная инвентаризация — [asset-pack-inventory.md](asset-pack-inventory.md).

## Подготовка

- Для 10 паков выбраны штатные вложенные версии URP. Они содержат полный
  набор FBX; у Hospital есть две дополнительные модели по сравнению с HDRP.
- Industrial Set, Ultimate Nature Starter и маленький Ultimate Bundle
  готовятся из основного архива. Bundle — настройки/сцена, не дополнительная геометрия.
- Настройки `Packages/manifest.json` и `ProjectSettings` из демопроектов
  не копируются в настройки игры.
- Исключены TutorialInfo/Readme, демонстрационные `.cs`, `.wlt`, вложенные
  архивы других pipeline и HDRPDefaultResources. `ReadmeEditor` поставщика
  дублирует имеющиеся классы и автоматически загружает раскладку редактора.
- Пути моделей и структуры папок поставщиков сохраняются. Игровой код,
  список сцен сборки, карта реестра и открытая сцена не изменяются импортом.

## Конфликты GUID

В нескольких паках Hivemind одинаковые GUID принадлежат разным префабам.
Пример: `SM_Shelf` в Post Apocalyptic Town и Rural Town. Прямой массовый
импорт создаёт неоднозначные ссылки и может подменять объекты между паками.

66 повторных префабов получают отдельные детерминированные GUID; ссылки в
сериализованных ассетах соответствующего входящего пака переписываются.
Остальные GUID сохраняются. Исходные архивы и исходная распаковка неизменны:
правятся только подготовленные копии под `Temp/LevelDesign/EnvironmentImport/ready`.
Таблица старый → новый хранится в `guid_remaps` манифеста импорта.

Бинарные TerrainData не редактируются наугад: подготовка проверяет, что в них
нет конфликтующих ссылок (ASCII GUID, сырые байты и представление четырьмя
little-endian словами). При обнаружении такой ссылки подготовка прекращается.

Подготовлено 8036 новых ассетов, около 11.08 ГиБ данных, включая 2060 FBX,
2565 префабов и 1700 материалов; три одинаковых существующих входящих ресурса
переиспользованы между паками. Неразрешённых конфликтов путей/GUID нет.

## Инструменты

В `Tools/AssetCatalog/`:

1. `stage_environment_packs.py` — распаковка 13 архивов вне игрового Assets,
   с чекпоинтами для возобновления.
2. `inspect_nested_packages.py` — извлечение штатных вложенных версий URP.
3. `plan_environment_import.py` — проверка полноты, сравнение с имеющимися
   файлами проекта, разделение конфликтующих GUID и манифест импорта.
4. `import_environment_files.py` — перенос ассетов под действующим замком
   Unity. Файлы создаются эксклюзивно, существующие данные не перезаписываются.
5. `upgrade_environment_materials.cs.txt` — тело метода для Unity MCP
   `execute_code`: штатные конвертеры Built-in → URP только для новых
   материалов из манифеста, с отчётом `material-upgrade.json`.
6. `verify_environment_import.cs.txt` — тело метода для Unity MCP:
   проверка GUID, загрузки ассетов, мешей и материалов префабов, ошибок
   шейдеров; отчёт `unity-verification.json`.
7. `diagnose_materials.py` — анализ отсутствующих шейдеров и прямых ссылок
   префабов; отчёты `material-diagnosis.json` и `catalog-eligibility.json`.

Во время переноса автообновление AssetDatabase приостанавливается; после
переноса разрешается и выполняется единый Refresh. Операция проходит под
замком `codex-environment-import`. При прерывании сначала проверять
`copy-progress.json` и возвращать автообновление редактора.

Артефакты: `Temp/LevelDesign/EnvironmentImport/import-plan.json`,
`resolved-packages.json`, `copy-progress.json`. Это временные отчёты,
исходники инструмента и этот документ сохраняются в проекте.

## Статус

### Текущий набор

По решению пользователя Ultimate Nature Starter удалён из проекта 2026-10-02:
стилизованная природа не подходит военной теме. Удалены 97 ассетов пака
(27 FBX, 27 префабов, 10 материалов), папки и `.meta`. Убрана ссылка
`com.unity.input.settings.actions` на его Input Actions из Build Settings.
Исходный архив в кеше Asset Store сохранён.

Осталось **12 паков, 7939 ассетов, 2033 FBX, 2538 префабов, 1690 материалов**.
После удаления повторная проверка GUID и ссылок: 2535 префабов с целыми
ссылками, те же три повреждённых префаба поставщика. Android compile gate
повторно прошёл без ошибок. В полном аудите осталось 911 замечаний:
893 дополнительных материала HDRP, 15 меш-ссылок и три настройки HDRP.

`Tools/AssetCatalog/catalog-policy.json` исключает
`Assets/InnerverseInteractive/` из подготовки, переноса, проверки,
конвертации материалов и подбора кандидатов. Первоначальный манифест
сохраняется как история распаковки 13 паков; каталог учитывает исключение.

Для бинарных TerrainData и LightingData этих паков в `.gitattributes`
добавлены исключения `binary`: общее правило текстовых `*.asset` иначе
меняет CRLF-байты TerrainData при добавлении в Git. Перед коммитом
проверено совпадение исходных и индексированных blob-хешей всех девяти
бинарных `.asset` оставшихся паков.

### Первоначальный импорт и выявленные ограничения

Импорт выполнен 2026-10-02: скопированы все 8036 ассетов с проверкой SHA-256,
Unity закончила Refresh. GUID всех 8036 ассетов разрешаются в ожидаемые пути.
Штатные конвертеры Unity перевели 62 новых материала Built-in → URP.
`AndroidCompileGate.Run()` — **PASS**, ошибок компиляции нет.

Из 2565 префабов **2562 имеют целые ссылки на меши, материалы и шейдеры**.
Три префаба содержат 15 ссылок на отсутствующие меши; соответствующие GUID
не разрешаются и таких FBX нет в распакованных вариантах паков:

- Hospital: `SM_Room_Door_02b_SM_Room_Door_02c.prefab` и
  `SM_Room_Door_02b_SM_Room_Door_02b.prefab`.
- Modular Wooden Buildings: `SM_ShowcaseFloor.prefab`.

Они сохранены как содержимое поставщика, но исключены из первичного
списка кандидатов `catalog-eligibility.json`.

Остальные ограничения исходных паков:

- 893 дополнительных материала внутри папок мешей ссылаются на один
  отсутствующий HDRP/Lit shader GUID `6e4ae4064600d784cac1e41a9e6f2e59`.
  Прямых ссылок на них из импортированных префабов нет; материалы самих
  префабов проверены отдельно. Просмотр голого FBX может использовать эти
  материалы, поэтому для визуального каталога брать поставляемые префабы.
- Три настройки HDRP из Ultimate Bundle не загружаются без HDRP; они не
  назначались настройками игрового проекта.
- Бинарные `UNS_Terrain.asset` и демонстрационный `LightingData.asset`
  Nature не загружаются в этом редакторе. Модели и префабы Nature загружаются.
- Четыре материала старых Particle shaders сохранены; визуальную работу
  соответствующих эффектов в URP этот проход не подтверждает.

Полный аудит намеренно сохраняет 913 замечаний: 893 материала, 15 меш-ссылок
и пять незагруженных служебных/демонстрационных ассетов. Это не полностью
чистая поставка. Импорт и зелёная компиляция не подтверждают пригодность
каждого объекта для Quest или соответствие блоку LD_Alphabet.
