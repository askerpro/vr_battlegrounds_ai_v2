## Вибрация

| Дата | Решение |

| 2026-10-08 | Подбор — в редакторе Unity в Play Mode через Quest Link, ползунками; правка должна сразу действовать на контроллеры. Экран настройки на планшете отклонён и удалён. |
| 2026-10-08 | Клип — это форма заданной длины (`UxrHapticWaveform`). Правила воспроизведения (сила, приоритет, пауза повтора, кулдаун, вторая рука) — в `UxrHapticClip` точки интеграции, расширенном SDK-патчем 66. Отдельные каталог/пресеты/Id сигналов не нужны. |
| 2026-10-08 | Один владелец мотора: `HapticService`. Прямые `SendHapticFeedback`/`SendHapticImpulse`/`StopHaptics` вне `UnityXRHapticDevice` запрещены (на Quest каждый вызов обрывает чужую вибрацию). |
| 2026-10-08 | Вибрация — только на руке локального игрока; рука чужого аватара и бота — тишина. |
| 2026-10-08 | `PocketHaptics` заменить общей системой, а не скриптом на сценарий. |
| 2026-10-08 | Гибель — максимум 1,5 с (форма `Death`). |
| 2026-10-09 | Готовность кармана подобрана в шлеме: Steady, сила 0.08, приоритет Low, без паузы. |
| 2026-10-09 | Любое «рука готова взять предмет» даёт тот же отклик, что готовый карман (свободный предмет, предмет в якоре, слот арсенала, гнездо магазина). |
| 2026-10-09 | Вторая рука к предмету, который уже держит другая рука (или к его части — цевьё, затвор), — гул вдвое тише (`SecondaryHandGain` 0.5). |
| 2026-10-09 | Тесты — на подтверждённую логику: сначала шлем, потом тесты. Тест покрытия должен перечислять якоря и предметы без отклика, чтобы ничего не забыть. |
| 2026-10-09 | График формы с перетаскиванием точек (X — длительность, Y — сила) — отложен. |

## Отклик взаимодействий (архитектура)

| Дата | Решение |
|---|---|
| 2026-10-09 | Отклик — обычный префаб-GO из компонентов Unity (`HapticPlayer`, звук, подсветка…). Включение GO = отклик играет. Своих «слотов» и автоплея нет. |
| 2026-10-09 | «Клип» и «проигрыватель клипа по правилам» разделены: `UxrHapticClip` — что играть, `HapticPlayer` — когда/как (режим, рука). |
| 2026-10-09 | Самое частное побеждает: свой отклик предмета → якоря → глобальный `InteractionFeedbackConfig`. Чужие префабы не правятся — работают значения по умолчанию. |
| 2026-10-09 | Один исполнитель `InteractionFeedback`. Готовность берётся у SDK (кандидат хвата — патч 67, кандидат якоря — `GetAnchorPlacementCandidate`), своих расчётов близости нет. |
| 2026-10-09 | Проход SDK «рука рядом с якорем» (`GrabberNear`, патч 26) обратно НЕ включать: его отключение дало заметный прирост производительности. Обходиться кандидатом хвата. |
| 2026-10-09 | Флаг «сетевое событие» на слоте отклика (`NetworkedFeedback`): звук вставки магазина слышат все, вибрация и подсветка — только свой игрок. Состояния готовности всегда локальные. |
| 2026-10-09 | Автоматизация префабов (сборщики, миграции) для пользователя почти бесплатна, но выбран путь «значения по умолчанию в конфиге», чтобы не править префабы других агентов. |
