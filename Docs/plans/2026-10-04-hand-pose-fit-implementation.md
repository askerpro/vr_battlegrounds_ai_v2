# Анализатор посадки кисти — план реализации

> Для исполнителя: использовать `superpowers:executing-plans`, выполнение в текущем чате.

**Цель:** рабочая первая версия измерений и PNG/JSON для статического Fixed/Blend-хвата.
**Архитектура:** отдельная Editor-сборка, изолированный snapshot, чистая геометрия, единый отчёт и окно.
**Стек:** Unity 6000.4.1f1, UltimateXR, PreviewRenderUtility, Newtonsoft.Json, NUnit.
**Спецификация:** [согласованный дизайн](../hand-pose-fit-analysis.md).

## Общие ограничения

- Только `Assets/Editor/VR_Battlegrounds/Avatars/HandPoseReview/`, без изменений игровых ассетов/SDK.
- Текущий общий checkout `add-guns` нужен для проверки существующих префабов в открытой Unity; чужие правки сохраняются.
- Никаких новых норм качества: дистанция и пересечения отдельно, неизвестный знак — `null`.
- Геометрические тесты проверяют известные формы; игровые тесты поз/аватара не изменяются.
- Коммит кода — после проверки пользователем; сейчас подготовить проверенный рабочий результат.
- Замок только на готовый пакет компиляции/проверок, освобождение до разбора результата.

## На что обратить внимание при ревью

- Разные скелеты, общий SMR обеих рук, дополнительные слои перчатки: фильтрация по костям выбранной руки.
- Открытые/неманифолдные/неориентированные поверхности: отсутствие ложного нулевого проникновения.
- Вложенный магазин/помпа, fallback, недоступная сторона: точная идентичность случая и явные ошибки.
- Масштаб, Blend, временное смещение: измерения в метрах с единым преобразованием, временные копии удаляются.
- Неподдерживаемые snap/IK/двуручный контекст: явный отказ или неполный отчёт.

## Остающиеся границы

Полная модель контроллера и поддержка второй рукой явно неподдерживаемы. Контактные маски приблизительны; некоторые поверхности открыты и дают неизвестный знак. Нет итогового балла и калибровки допустимого дефекта. Принятие полезности инструмента и коммит кода — после проверки пользователем в Unity.
