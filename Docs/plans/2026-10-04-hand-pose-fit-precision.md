# Анализатор хвата — точность и игровой снимок

Пользователь разрешил реализацию рекомендаций 2026-10-04. Выполнение в текущем чате, без изменения игровых хватов и автоматического назначения поз.

## Контракт

- Существующий Editor-анализ сохраняется. Новый источник — фактически схваченный предмет после `UxrManager.AvatarsUpdated`; геометрия замораживается до следующего кадра, тяжёлый отчёт обрабатывается отдельно. Никаких вызовов Shoot/Grab/Release ради съёмки.
- Единая система координат: метры в осях захваченного корня предмета; его масштаб уже включён в BakeMesh/матрицы Renderer.
- Пальцы размечены до фаланги по весам костей. Это приблизительная маска, а не автоматически подтверждённая подушечка. Пользовательские контактные регионы предмета сопоставлены с зонами кисти; несовпадение не получает положительный контакт.
- Контакт 0–2 мм включительно. Дополнительно: нормали пары, распределение площади по диапазонам, связность контактных граней, самопересечения разных зон и пересечения второй руки.
- При явном задании проверенного замкнутого mesh объёма рукояти считать локальное проникновение отдельно от всей видимой геометрии. Непроверенный объём не выдаёт подтверждённый знак. Автоматически закрывать импортированный меш или использовать convex-оболочку вместо него нельзя.
- Сохранять суставы, относительные повороты, параметры выборки и результат удвоенной выборки по желанию. Достоверность каждого показателя отдельная: измерено / приближённо / неизвестно.
- Серия отчётов разных состояний и сравнение с явно принятым эталоном: сопоставимость конфигураций проверяется, нормы качества не выдумываются. Разные аватары сравниваются по зонам/долям; сырые координаты и число точек не становятся оценкой качества.
