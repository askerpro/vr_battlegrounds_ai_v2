# T-40: общее пространство головы в VR

> Отчёты в `Docs/tasks/report/` — локальные, игнорируются Git и не входят в коммит.

> Исполнение: superpowers:executing-plans. Пользователь сообщил раздельное ощущение эффекта глазами и разрешил исправление 2026-10-05.

**Цель:** эффект ощущается объёмом вокруг игрока, с одним центром и геометрией для обоих глаз.

**Причина в исходнике:** Flow shader обрезал реальные 3D частицы через ComputeScreenPos каждого глаза;
World shader рисовал полноэкранную периферию и экранные полосы. Mono-стенд не выявлял эту разницу.

**Решение:** одна head-space сетка и альфа для частиц; реальная сферическая оболочка вместо
полноэкранной рамки; окружение меняет только цвет, его экранный узор удаляется. Камера UxrAvatar
служит центральной позой головы. XR остаётся ответственным за две проекции одной геометрии.

**Границы:** никаких правок authority/таймеров/геометрии штрафа, SDK, префабов или камеры post-processing.
Новые механические NUnit до подтверждения не создаются. Коммит после проверки пользователем.

- [x] Добавить общий EffectRadius в визуальный профиль и окно настроек (1–3 м, по умолчанию1.5).
- [x] Flow: перенести периферийную альфу из shader screen UV в общие вершины относительно центра головы;
  отодвинуть минимальный радиус частиц, оставить один поток/снимок Mesh+Matrix на кадр.
- [x] CameraEffect: заменить Rim DrawProcedural на DrawMesh общей сферической оболочки, Resources/XR shader.
- [x] World shader: убрать экранные полосы и проход рамки, оставить одинаковое преобразование цветов.
- [x] Native stereo probe: две камеры с одним центром эффекта и IPD64мм видят разные проекции одной Mesh,
  маска центральной области определяется совместным объёмом; mono preview и вторая камера сохраняются.
- [x] AndroidCompileGate, ShaderUtil, изолированная очистка; снять lock сразу после пакета.
- [x] Обновить действующие требования/проверочный список T-40, README, gameplay, troubleshooting, CHANGELOG.

Шлемная приёмка остаётся обязательной границей: native stereo-проекция подтверждает геометрию,
но не ощущение объёма, комфорт или поддержку конкретного Oculus режима на Quest.
