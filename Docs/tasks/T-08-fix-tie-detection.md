## Что делать

Две функции с одинаковой ошибкой:

- `Assets/Scripts/GameModes/EliminationMode/SetManager.cs:86-107` — `OnRoundEnded`
- `Assets/Scripts/GameModes/EliminationMode/EliminationMode.cs:227-245` — `OnSetEnded`

Обе идут по словарю с `highestRounds = 0` и веткой:

```csharp
else if (kvp.Value == highestRounds) isTie = true;
```

На первой итерации `0 == 0`, и ничья взводится до того, как посчитан хоть один результат.
Дальше исход зависит от порядка обхода `Dictionary`, который в C# не гарантирован.

Переписать в два прохода:

1. найти максимум по значениям;
2. посчитать, сколько ключей набрали этот максимум.

Ничья — когда таких ключей больше одного. Отдельно решить, что считать результатом,
если максимум равен нулю (никто не выиграл ни раунда) — сейчас это неявно ничья,
и так, вероятно, и должно остаться, но зафиксировать явно.

## Границы

Только подсчёт победителя и ничьей. Порог победы (`roundsToWin`, `setsToWin`) и условия
завершения сета/матча не трогать — если они окажутся неверными, это отдельная находка.

Не трогать структуру машины состояний — это [T-09](T-09-explicit-round-fsm.md).

## Как проверить

Тест `Счёт_2_1_это_победа_а_не_ничья` из [T-07](T-07-test-assembly-and-first-tests.md)
должен позеленеть. Добавить к нему ещё три случая:

- 0:0 — ничья;
- 1:1 — ничья;
- 3:0 — победа.

## Готово, когда

- Обе функции считают в два прохода.
- Тест из T-07 зелёный, три дополнительных случая тоже.
- Поведение при нулевом максимуме описано комментарием.
