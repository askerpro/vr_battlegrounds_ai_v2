Разбор — в [`../audit/network-audit-2026-08.md`](../audit/network-audit-2026-08.md#vr-03--средний--рефлексия-во-внутренности-ultimatexr-нигде-не-зафиксирована).

## Проблема

Игровой код читает и пишет приватные поля UltimateXR через рефлексию:

| Где | Что |
|---|---|
| `PhysicalSpaceSyncManager.cs:43` | `UxrStandardAvatarController._bodyIKSettings` |
| `PhysicalSpaceSyncManager.cs:377` | `UxrStandardAvatarController._bodyIK` |
| `PhysicalSpaceSyncManager.cs:383` | `UxrBodyIK._avatarForwardPosRelativeToNeck` |
| `PhysicalSpaceSyncManager.cs:390` | `UxrBodyIK._neckPosRelativeToEyes` |
| `ArsenalWallController.cs:146` | `UxrGrabbableObject._autoCreateStartAnchor` |

Формально это не правки SDK, поэтому в `sdk-patches.md` они не попали. Но зависимость
от внутренних имён чужой библиотеки жёсткая, а сломается она молча: при обновлении
UltimateXR рефлексия не даст ошибку компиляции — просто вернёт `null`, и калибровка роста
перестанет работать. Худший вид зависимости — невидимый до рантайма.

## Что делать

### 1. Новый раздел в `Docs/UltimateXR/sdk-patches.md`

«Зависимости от приватных членов SDK» — таблица выше плюс на каждую запись: зачем нужно,
что сломается при исчезновении, есть ли публичная альтернатива.

Это не «патч», но файл — единственное место, куда смотрят при обновлении SDK, и логично
держать такой список там же.

### 2. Громкий отказ вместо тихого

Сейчас при ненайденном поле код молча выходит:

```csharp
var bodyIKField = typeof(...).GetField("_bodyIK", ...);
var bodyIK = bodyIKField?.GetValue(controller);
if (bodyIK == null) return;   // ← тишина
```

Заменить на `GameLog.Error` с именем поля и типа. Тогда после обновления SDK поломка
будет видна в первую же секунду, а не через неделю жалоб на калибровку.

### 3. Отметить кандидатов на публичный API

Часть случаев закрывается механизмом `.Custom.cs`, который в проекте уже используется
(Патч 2 в `sdk-patches.md`). Например, `_autoCreateStartAnchor` можно открыть публичным
свойством. Не делать в рамках этой задачи — только отметить в таблице.

## Границы

Документация и логи. **Не переписывать саму рефлексию** — замена на публичный API меняет
поведение и требует проверки в шлеме, это отдельная работа.

## Как проверить

Компиляция чистая. Временно переименовать поле в SDK и убедиться, что в консоли появилась
внятная ошибка вместо тишины; вернуть имя обратно.

## Готово, когда

- Раздел в `sdk-patches.md` есть, все пять точек перечислены.
- Ненайденное поле логируется как `Error`.
- Кандидаты на вынос в `.Custom.cs` отмечены.
