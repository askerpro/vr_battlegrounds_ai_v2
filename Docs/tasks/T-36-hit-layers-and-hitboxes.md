# T-36 · Слои попадания и хитбоксы по частям тела

| | |
|---|---|
| Находка | — (требование пользователя, 2026-09-29, по ходу T-35) |
| Блокирована | T-35 (трупы и призрак меняют состав слоёв и аватаров) |
| Уровень проверки | 1 (EditMode) + C (`weapon-hit-damage`) |
| Оценка | 2–3 дня |

## Требование

Сформулировано пользователем:

> Можно переделать слои для пули — это скорее всего случайно подобранные слои. Можно сделать слой для пуль.
> Сразу сделай тесты и проверь, что у всех аватаров есть куда стрелять — сделай оптимальные хитбоксы
> (голова, руки, ноги, торс — мы потом по ним будем измерять урон в зависимости от точки попадания).

## Что сейчас

- Маска попадания оружия (`UxrShotDescriptor.CollisionLayerMask`) — `Default|Ground` (T-28), подобрана по факту.
- Хитбоксы аватаров — сплошные коллайдеры на геометрии (у киборга — `MeshCollider` мешей), на слое `Default`, —
  тот же слой, что геометрия карт. Поэтому ни трупы (T-35), ни эффекты нельзя отделить от «мира» слоями:
  трупу пришлось выключать столкновения с телами попарно.
- Части тела у хитбокса нет — урон по зоне попадания считать не из чего.

## План

1. **Слои.** `Hitbox` — хитбоксы игроков; маска пули = статичный мир + `Hitbox` + мишени. Слой мишеней и предметов,
   в которые стреляют, — решить по сценам (Grep слоёв в картах и префабах).
2. **Хитбоксы генерирует сборщик** по гуманоидным костям (как трупы в T-35): голова (сфера), торс (капсула/бокс
   таза и груди), плечо/предплечье ×2, бедро/голень ×2 — триггер-нет, сплошные, кинематические, на слое `Hitbox`.
   Компонент `Hitbox` с частью тела (`BodyPart`: Head, Torso, Arm, Leg) — под будущий множитель урона. Сплошные
   коллайдеры геометрии снимаются. Для аватаров без гуманоидного рига (киборг) — по костям UltimateXR.
3. **Урон пока не меняется** — только данные для него: `UxrDamageEventArgs.RaycastHit.collider` → `Hitbox.Part`.
4. После — `Corpse` снова разделяется слоями: выключение столкновений попарно (`Corpse.IgnoreEverythingButStaticWorld`)
   можно упростить.

## Проверки

- Каждый аватар реестра: все части тела на месте, на слое `Hitbox`, сплошные; луч из 8 направлений в центр каждой
  части попадает в хитбокс этой части (EditMode, `Physics.Raycast` по инстансу).
- Маска каждого оружия включает `Hitbox` и мир, не включает `Corpse`, `Player`, `SpawnZone`, `LocalHead`.
- `ShootingTargetTests`, `WeaponHitDamageScenario` (ярус C) — зелёные.
- Призрак (T-35) — без хитбоксов, как и был.
