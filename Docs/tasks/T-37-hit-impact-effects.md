# T-37 · Эффект попадания по игроку: звук и кровь

| | |
|---|---|
| Находка | — (требование пользователя, 2026-09-29) |
| Блокирована | T-36 (эффект привязывается к части тела и точке попадания в хитбокс) |
| Уровень проверки | 1 (EditMode) + шлем (вид и звук) |
| Оценка | 1–2 дня |

## Требование

> Надо сделать какой-то импакт эффект (звук + кровь, визуальное подёргивание от попадания пока не будем).

## План

- **Кто играет.** Эффект — событие, не состояние: каждая машина симулирует снаряд и получает попадание
  (`UxrActor.DamageReceived` / `UxrDamageEventArgs.RaycastHit`) — эффект играется там же, локально, без RPC.
  Проверить, что попадание не отменено правилом режима (разминка — урона нет; эффект тоже нет или «холостой» —
  решить с пользователем).
- **Кровь** — пул частиц (брызги по нормали + капли), на Quest — дешёвые billboard-частицы, без света и
  прозрачной сортировки тяжелее одного прохода. Декаль на трупе/полу — не в этой задаче.
- **Звук** — пул `AudioSource` в точке попадания, набор клипов по части тела (голова — отдельный), 3D, приглушение
  на расстоянии.
- Свой игрок (в шлеме) — без крови в камеру; звук попадания по себе — отдельный, «изнутри».
- Бюджет: не больше N эффектов одновременно (пул), замер в `perf-stress-test`.

## Проверки

- Попадание в хитбокс вызывает эффект с точкой и нормалью попадания; в разминке — по решению выше.
- Пул не растёт без предела при очереди.
- Руками в шлеме: видно, слышно, FPS.

## Пункт 2 — реакция тела на попадание (добавлено 2026-09-29)

Требование пользователя: «при попадании небольшое влияние на куклу, но ни камеру, ни руку сдвинуть не могут — чуть
наклонить торс в бок». То есть на позицию игрока и оружие не влияет никак, только визуальный эффект.

- Наклон груди/позвоночника по направлению пули, 5–8°, затухание ~0,2 с; только для **чужих** аватаров (себе — нет:
  тело, которое гнётся без движения игрока, в VR неприятно).
- Добавлять **до** решения IK рук (этапы обновления аватара UltimateXR): тогда IK вернёт кисти к контроллерам и
  оружие останется в ладони; камера — от шлема, её наклон не касается. Учесть Legs Animator.
- Без сети: попадание симулирует каждая машина — реакция локальная, как эффект.
- Проверка: EditMode — после наклона кисти остаются в целях IK (допуск), камера не сдвинута; шлем — вид.
