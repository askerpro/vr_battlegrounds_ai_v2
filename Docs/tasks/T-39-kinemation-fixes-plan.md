## Границы

Исправления применены только к SRM12, R08, AK105, Viper, MKR9, Herrington, Mk14 и TR15, их магазинам и необходимым общим контрактам. Остальные WeaponRegistry/Hands-префабы не пересохранялись. Общий Hands-сборщик поддерживает раздельные области при последующей сборке, узкий KINEMATION Build устанавливает также motion.

Автоматическое согласование отклонило широкое применение к WeaponRegistry из-за изменения всех зарегистрированных префабов. Срез сужен до восьми KINEMATION; распространение на остальной реестр отложено. Build All не выполнялся.

Сохранённые основные меши и их положение совпали с источником. Исчезновение/вылет детали в игре пока не воспроизведены; формула bindpose и геометрия корпуса не менялись. Первое превью LoadPrefabContents не показало несколько деталей, тогда как изолированное превью тех же мешей их показало; это не доказательство исчезновения в игре.

При повторной записи region mesh доказан отдельный дефект CopySerialized: CPU bounds/vertices уже новые, GPU рисует прежнюю область; свежий Mesh из тех же CPU данных рисует новую. Baker теперь обновляет существующий Mesh через Mesh API, сохраняя GUID и инвалидируя GPU-буфер. Этот факт относится к новым region assets; он не доказывает причину исходного исчезновения деталей в игре.

Очередь и lock получены от оркестратора. ReferenceMap04 остаётся чистой, человеческий Play не запускался и не прерывался. Чужие изменения legs сохраняются отдельно. По прямому разрешению пользователя от 2026-10-03 подготовленный код сохраняется review-коммитом в отдельную ветку без переключения общего checkout. Этот коммит не означает принятие механики.

## Принятые контракты

- ActionPart описывает ход физического механизма; ActionGripPart/ActionGripContact — видимую ручку и контакт руки. MKR9 использует ChargingHandle, TR15 — Charger, Viper — заднюю насечку Bolt. Поза пальцев и вращение align-трансформов сохраняются.
- Primary, Support, Action, Insertion имеют отдельные visual holders и вырезанные из выбранной поверхности region meshes. Нормальное смещение 0,3 мм исключает наложение полигонов; основной меш не режется. Pistol Support расположен на рукояти.
- AnchorPlacementReadiness читает уже выбранную SDK пару якорь/рука. Повторная проверка исключает чужую/неактивную руку, несовместимость, занятое гнездо, parent dependency и предмет в двух руках. PocketReadiness использует тот же принимающий контракт; выдача кармана сохраняется.
- WeaponMagazineAnchorHighlight — единственный писатель Insertion visual. SDK ActivateOnCompatibleNear для него пуст. При disable/смене manager старый экземпляр освобождается.
- Mechanical motion содержит только разрешённые каналы относительно корпуса. Fire, Empty и Manual — независимые nullable циклы; GUID/subasset ID источника сохранены. Mk14 выбирает известный .anim, неоднозначное имя клипа останавливает экспорт.
- Export сохраняет ключевые времена и дополняет сетку не реже 120 Гц, адаптивно уточняет четверти интервалов. Независимые контрольные времена 1/3 и 2/3 проверяют допуск 1 мм / 0,5°.
- ProjectileShot/ProjectileShotReplayed запускают один косметический цикл; Empty определяется после списания патрона. Cosmetic playback не вызывает Shoot/Reload. Trigger.rotation остаётся у UXR.
- Manual grab получает приоритет: residual переносится в physical Slide с сохранением мировой позы и обновлением того же снимка UXR Grabbing. Контакт не меняет local frame под рукой. Внутренний открытый Bolt удерживается до catch; отменённый catch сохраняет открытую позу. Повторный zero-residual хват сохраняет уже зачтённую тягу.
- Reload остаётся только у существующего AutomaticWeaponSlideFeedback с StateEventAuthority. Косметическое открытие не засчитывается как ручная тяга: нужны ещё 2 мм; Empty диапазон включает открытую позу и запас 4 мм.
- R08 анимирует визуальный Cylinder текущего вставленного магазина и независимые каналы Ammo_01…08/Ejector. Статический collider и прежние пути магазина сохраняются; отключённый MeshRenderer не рисует повторный барабан.
- SRM12 Fire включает ручную болтовку, поэтому сохранён как Manual data и не проигрывается автоматически после выстрела. Нового поворотного VR-затвора в этом срезе нет.

## Пределы автономной проверки

Три прежних KinemationWeaponTests сравнивают TranslationLimits исключительно с Fire: Viper, Herrington и TR15 теперь требуют диапазон Empty и дополнительную реальную тягу. Тесты пока не переписаны по правилу пользовательского подтверждения.

Четвёртый отказ — бюджет R08: тест суммирует все MeshFilter, включая отключённый статический Cylinder и его visual-child, и получает 24605. Реально включённые обычные renderers рисуют 20877, ниже прежнего бюджета 22000. Геометрия не удваивается при рендеринге.

Reflection probe проверяет преобразования и переходы, но не SDK Compute, движение контроллера, actual anchor release, сетевой replay и VR-восприятие. Статическое preview не заменяет проверку анимации и хвата в игре. Приёмка T-39 остаётся открытой.
