## Требование

Пуля пробивает тонкие укрытия с потерей урона, толстые — никогда, листву и сетку пролетает. Классы укрытий —
[LD-27…LD-31](../level-design/level-design-principles.md). Сейчас закладывается только механика; силу пробития оружия настроит
пользователь отдельно.

## Класс проблемы и решение

Правило «пуля останавливается на первом не-акторе» было зашито в SDK без точки расширения. Решение — одна точка
решения (`UxrWeaponManager.ProjectilePenetration`, патч SDK 32), логика — у игры (`WallPenetration`), класс укрытия —
генерация по имени (`CoverClassRules` + `Apply Cover Classes`), а не ручная расстановка; согласованность держит тест.

## Как устроено

- **Класс укрытия** — `CoverSurface` на объекте, суффикс имени `_Hard`/`_Soft`/`_Visual`
  (`LD_Wall_Mid_Soft`). Без разметки — Hard. Компонент ставит `Tools/VR Battlegrounds/Gameplay/Apply Cover Classes`,
  руками настраивается только `PenetrationModifier` у Soft (pm по CS: дерево и картон 3, пластик 2).
- **Толщина** — обратным лучом по тому же коллайдеру из точки в 90 юнитах (2.29 м) за входом, как `TraceToExit` CS.
- **Потеря — формула CS** (восстановлена по коду CS:GO, для CS2 по открытым данным та же):
  `(1/pm)·t²/24 + урон·0.16 + (3.75/пробитие)·3·(1/pm)`, `t` — в юнитах CS (дюймах). Потеря больше урона или остаток
  меньше 1 — стоп; до 4 пробитий; pm < 0.1 — не пробивается. Hard не пробивается никогда (отличие от CS, LD-27).
- **Пробитие оружия** — по CS2 в `WeaponInfo` → `PenetrationPower` выстрела через `Apply Weapon Balance`:
  пистолеты, SMG, Nova — 1; M4A4, AK-47, Desert Eagle — 2; SSG 08 — 2.5. Сверяет `WeaponBalanceTests`.
- **Эффекты** — обычное попадание на входе, та же декаль на выходе; Visual — без эффектов.
- **Сеть** — ничего нового: пулю ведёт каждая машина, урон вычитает сервер, геометрия одна.

## Что совпадает с CS2

**Урон пули после стены.** Число попаданий до убийства — нет, пока голова ×3 и нет брони:
[T-43](T-43-cs2-hits-to-kill-parity.md).

## Проверка

- `WallPenetrationTests` — потеря сверена с числами, посчитанными вручную по формуле; лимиты; настоящая пуля через
  `UpdateProjectiles`: Deagle сквозь 10 см дерева с 50 урона — 39.91, Glock — 38.04, две стены по 5 см — 31.73,
  неразмеченная — ничего, Visual — полный урон, без хука — поведение SDK.
- `CoverClassTests` — разметка во всех префабах и сценах совпадает с именами; Soft имеет сплошной коллайдер.
- `WeaponBalanceTests` — пробитие каждого ствола как в CS2, в каждом выстреле префаба.

## Не проверено и не сделано

- **Константы CS2 не сверены замером.** Публичный порт для CS2 использует 0.18 вместо 0.16 и толщину в сантиметрах —
  возможно, в CS2 формулу меняли. Эталонный замер в CS2 (консоль «Damage Given») и тест на него — в T-43.
- **Таблица pm материалов CS2** (`surfaceproperties*.txt`) не получена — известны только правила дерева/картона (3) и
  пластика (2). Остальные материалы Soft — заполнить из файлов игры.
- Soft-укрытий на картах пока нет: нужны объёмные префабы реальной толщины (LD-30) с суффиксом `_Soft`.
- В тестах пуля неподвижна (луч кадра на всё поле) и выстрел собран вручную — полёт с настоящей скоростью и реальный
  префаб оружия не проверены; шлем, сеть, вид декали на выходе — тоже.
- Отдельный звук пробития и метка «сквозь стену» в `DebugHitMarkers`.
