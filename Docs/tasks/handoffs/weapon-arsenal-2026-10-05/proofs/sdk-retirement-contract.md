# Конечное освобождение generated graph — producer handoff

Дата: 2026-10-05. Узкий read-only source review; Unity, импорт, Play, Assets и старые safety gates не менялись. Этот отчёт дополняет `../contract-v2.md`, а не объявляет retention конечным cleanup.

**Рекомендация:** SDK7 можно передать root на отдельный SourceGO. Network allocation API пока требует описанный ниже scene placement и upstream barrier. Единственный выбранный production barrier — реальная замена сцены карты существующим владельцем MapLoader/Mirror, включая повторную загрузку той же карты. In-place rebuild в ещё живой сцене этим вариантом не поддерживается. Цена отказа generation после выделения объектов — загрузка карты заново, с обычным изъятием снаряжения и сбросом её runtime состояния. Никакой receipt не становится владельцем карты, игроков или выданных предметов.

## Обязательный контракт фабрики

Перед первым allocation Network получает **тот же** реальный `MapRunScope`, captured Key и explicit loaded Scene от map producer. Producer разрешает Scene через actual MapRootBindings.Gameplay/placementRoot, проверяет scene handle, активную загрузку и placement frame; отказ происходит до создания Container. Проверка только Scene.name либо SceneManager.GetActiveScene недостаточна. DDOL/bootstrap scene не является допустимым target. Network не выбирает карту и не вычисляет новый run key.

Минимальная корректировка API: `CreationReceipt(scope, targetScene)` и `CreateReceiptedInstance(prefab, receipt)`. Scene в receipt — immutable proof выделения, не самостоятельный lifetime owner. Фабрика:

1. Проверяет scope/key/targetScene.IsValid/isLoaded и main-thread synchronous creation; никакого yield между проверкой и первым размещением.
2. Создаёт blank Container, немедленно записывает exact returned allocation в receipt, делает его inactive и **MoveGameObjectToScene(Container, targetScene) до Instantiate**. Пока это пустой GO с Transform, внешним callbacks он не опубликован. Если native placement не завершился, generation не admitted; failure не маскируется удалением произвольной active scene.
3. Instantiate выполняется под этим inactive Container. Returned Root записывается до suppress/detach/InstanceCreated. Root и все born descendants должны иметь targetScene; после detach Root остаётся в targetScene. Не опираться на предположение: native assertion перед callbacks и снова после них.
4. Final placement/parent/TRS устанавливаются до exact UID publication и dummy SerializeState. Prepare и immutable committed proof проверяют **Root и Container**, все exact owned allocations, их native scene handles/graph/role refs и final frames. Повтор с тем же hash читает original proof, не переснимает changed graph.
5. Новые factory children сначала записываются и размещаются в targetScene, затем получают owned parent. Поддержанные participants не вызывают DDOL, не переносят owned graph в другую scene/чужой parent, не добавляют посторонние descendants. Проверка после всех публичных callbacks отказывает при нарушении. Refusal не разрешает автоматический detach/destroy чужого объекта.

`MoveContainer` на стороне Composer **после** callbacks/publication не принимается как исправление: failure до этого шага оставляет orphan. Это ответственность единственного allocation owner Network, а решение когда закончить map lifetime остаётся у map producer.

Ошибки до allocation не требуют reload. Ошибки после успешного native размещения любого owned объекта закрывают run и запускают map-owner retirement. Неполученный returned allocation при native Instantiate exception требует отдельного native fault oracle; его отсутствие нельзя заменить graph discovery или обнулением registries. Placement API fault, escaped DDOL/subtree или unknown callback — named unsafe-retention/refusal, не finite success. Такой неподдержанный случай не получает разрешение нового run; root видит exact retained objects и ошибки.

## Один upstream barrier и последовательность

Это обязанности уже принятого MapBootstrap/MapLoader integration owner, а не метод самого receipt.

1. Read-only preflight принимает load request и фиксирует exact old Scene handle, текущий scope/key и replacement sceneName. Отказ/duplicate не закрывает scope, не меняет key, не изымает gear. MapLoader должен держать один accepted token до actual success/failure/cancel; текущий early IsLoading=false этого не обеспечивает.
2. После acceptance старый admission закрывается canonical MapRunAuthority.Retire/Fail. Scope cancel прекращает stage work/await continuations/подписки. Composer disposer закрывает только свои subscriptions, manifest и SDK registrations, сохраняет receipts для readonly native acknowledgment. MapRunAuthority остаётся единственным descriptor writer; status Failed/Retiring не является permission BeginRun.
3. Текущие server equipment/supply/loadout owners изымают свои gear через их штатный release + NetworkServer.Destroy/UnSpawn path. Strip выполняется ровно один раз за accepted preflight. Receipt не сканирует игроков, не очищает stock dictionaries или snapshot queues и не зовёт Gear teardown самостоятельно. Relay/queue owner отказывает captured old key после retirement.
4. `MapLoader.Instance.LoadMap(replacementSceneName)` инициирует Mirror normal scene replacement. Для cancellation/factory failure в уже loaded map replacement может иметь то же имя. Offline/online scene path Mirror сохраняется. В live session прямой SceneManager.LoadScene/UnloadScene для карты запрещён.
5. Map producer наблюдает unload **точного старого handle**, затем server scene completion новой expected Scene. Scene event callbacks только фиксируют observation/будят проверку; не запускают reentrant BeginRun. Event name/current active scene/один yield/Dispose return не заменяют predicate.
6. Перед следующим BeginRun на этом peer: все born Root/Container/descendant refs из receipts native-null; exact registered UID/typed sets/StateSave all+enabled+required+pending tuples и sync callbacks отсутствуют; owner callbacks unsubscribed, retained errors прочитаны. Receipt.TryAcknowledgeNativeRetirement подтверждает native-null только после этих observations, не уничтожает объекты. Producer использует свой existing keyed stage/token как gate; не вводить публичный arbitrary bool completed или второй canonical descriptor.
7. Только после barrier producer разрешает следующую sequence существующему authority. Новый RunKey даёт новые generated IDs. Повторное использование одного key в новом graph не допускается. Remote client LocalPlayable и snapshot application требуют его собственного local scene/identity barrier; server не ждёт это для server CompositionReady.

**Load failure/cancel:** old run остаётся Failed/Retiring, admission закрыт, старые async callbacks не могут commit. Если old scene ещё live, scene disposal не объявляется завершённым: accepted map owner предпринимает один явный recovery load валидной карты через тот же MapLoader после окончания/отказа предыдущей операции. До фактического old unload нового BeginRun нет. Если загрузчик/сеть не способны завершить recovery, остаётся named blocked run с receipts, а не ложный finite GREEN. При server stop клиенты следуют штатному Mirror offline path; если old scene продолжает жить, локальный pending receipt остаётся закрытым до actual scene/Play termination. Нельзя считать StopServer единственным доказательством native cleanup.

**Same-scene rebuild:** выбранный вариант — same-name **новая Scene instance** через этот normal load owner. Операция regeneration без scene replacement отказана до allocation. Чтобы поддержать её позже, потребуется конкретный иной native retirement barrier и отдельный root ruling; добавлять now второй hierarchy Destroy scheduler не рекомендуется.

## Поддержанные участники, foreign и динамическое снаряжение

Source census: единственный текущий `InstanceCreated +=` — `WeaponComponent.InstallPrefabHook/AttachByPrefab` (`Assets/Scripts/Arsenal/WeaponComponent.cs:42–59`). На slot/template prefab, которого нет в WeaponRegistry, обработчик no-op. Source template/role census должен проверить это до admitted factory. Если выбран weapon prefab и hook добавит Component через обычный AddComponent, текущий v2 exact born-component closure отказывает; добавление надо провести через явный owned factory contract, а не post-callback discovery ownership. Новый listener требует адресного source/native census, неизвестный listener отказ до activation/publication. Изменять stock CreateInstance путь ради generator нельзя.

Текущие `ArsenalSlotController.AssignNetworkItem:323` и `ArsenalMagazineOffer.Assign:70` parent-ят network stock в anchor; offer taken:95 detach-ит его. Это самостоятельные spawned предметы, не allocation receipt станции. `ArsenalMagazineSupply:149–172` создаёт stock через legacy identity/spawn path и `OnDisable/OnStopServer` снимает свои подписки; оно не становится частью SDK role manifest станции. Generation dispose в живой сцене не получает право Destroy дерева со stock.

`EquipmentStrip.ServerStripAll:51–65` + `PlayerLoadoutManager` владеют gear, текущие `AvatarTeardown:31–34` и `UxrGrabManager:356–371` рассчитывают на scene lifecycle removal при смене карты. DDOL `PlayerSession:303`, persistent manager root и SDK singleton остаются у своих owners. Native packet должен подтвердить отсутствие old grabs/anchor refs, а не расширить receipt до чужих typed/global sets.

Map owner имеет право заменить целую текущую карту с её scene-owned runtime stock; receipt этого права не имеет. Foreign object из другой lifetime, переподчинённый generated root, не превращается в map-owned: известный owner должен вернуть/retire его **до** unload; unknown attachment блокирует admitted destructive boundary и остаётся отчётным retention. Не обещается конечное cleanup произвольно нарушающего этот supported contract кода. Напротив, unknown graph не допускается к generation/admission и не уничтожается для получения PASS.

## Адресный producer handoff и source scope

Handoff от map owner: actual `(scope, key, target Scene handle, MapRootBindings, validated placementRoot, accepted-load token/local stage)`; retirement outcome owner возвращает после exact scene observation и receipt readback. Composer не конструирует scope из wire key и не выдаёт admission. MapRoot authoring validation может быть первоначальным source Scene predicate; разрешение Generated и live runtime orchestration остаются upstream integration.

Минимальные адреса следующей source wave:

- Network owner: `Assets/Scripts/Network/NetworkUxrIdentity.cs` — исправить born scene placement и scene proof; frozen role/UID/prepublication contract v2 сохраняется.
- Map owner, уже в принятом bootstrap plan: `Assets/Scripts/Managers/MapLoader.cs` (accepted request/outcome), `Assets/Scripts/Maps/Runtime/MapBootstrap.cs` (keyed orchestration/barrier), `Assets/Scripts/Network/GameNetworkManager.cs` (actual Mirror lifecycle notification), `Assets/Scripts/Managers/Series.cs` (accepted-load strip handoff). Это отдельный source set, не право этого reviewer писать Assets.
- Authority при необходимости: only guard BeginRun against pending native retirement **от existing map orchestrator**; не хранить новый graph/master и не добавлять Scene API в authority. Лучше единственный orchestration caller допускает BeginRun после barrier, как в accepted plan; public consumer BeginRun отсутствует.
- SDK7 core-only: separate `sdk-core-only.patch` из v2; serialization format, weapon/shotgun files и Network stock path не затрагиваются. Root может принять generic opt-in API неиспользуемым до Network integration. SDK docs обязательны product executor-у. Полный original8 diff сохранён; Network hunk не интегрировать как уже готовый runtime API.

## Native finite packet — конкретные cases и границы

Запускает medium только после root NativeGO под lease; старый RequirePreparedGate/NO_GO и proof packets не переписывать. В isolated fixture владелец имеет **свою** transient Scene и unload-ит только её; этот probe outcome не равен живому MapLoader integration. Play/debug/domain/network refusals старого packet должны быть выполнены фактически, не выключены ради прогона.

1. Container wrong active scene RED: own bootstrap-like Scene A active, valid target Scene B; создать через старый v2 factory, move только Root в B, unload B → Container остаётся A. Новый API: Container/Root/children born B, B unload → all native-null; A sentinel/scene/settings неизменны. Активация не требуется для этого начального mapping proof.
2. Failed/invalid/unloaded target, DDOL target, foreign placementRoot, canceled scope до allocation → created0/registered0/unchanged sentinel. При target placement/Instantiate fault фиксировать exact returned allocations и native outcome; неполученный orphan = отказ, не discovery ownership.
3. Cancel/fail после Container, после clone capture, после InstanceCreated, после каждого subsystem publication и после commit → own SDK cleared; pending в live B сохраняется и next BeginRun rejected; unload B → exact retirement acknowledgment, failures сохранены.
4. Same name old/new Scene handles: callback старого key на каждом delayed stage и повтор loading request отказаны без strip/key increment; normal reload даёт old-handle unload и native destruction **до** admission нового run. MapLoadCompleted ранний counter не разрешает barrier.
5. Real loaded map factory failure и recovery failure: accepted token/outcome + exactly-once strip; old live scene не выдаёт finite success; recovery success → единственное new run, old receipt missing everywhere. Dedicated/host отдельно, клиент completion отдельно.
6. Source-supported stock parented/taken/held/pocketed cases: current owners release/destroy once, network IDs/stock history/snapshot queue уходят по собственным paths, old station receipt никого дополнительно не destroys; no stuck grabs/anchor pointers. Перед generation admission stock ещё отсутствует.
7. Foreign GO/component attached Root или Container из другого lifetime, own subtree moved DDOL/other Scene, unknown callback → refused before admission; sentinel остаётся жив; receiver/receipt не detach-ит/Destroy-ит чужое. Если отдельный current owner вернул его, subsequent closure recheck возможен; unknown остаётся diagnostic pending.
8. SceneUnload/OnDisable/OnDestroy callback throw: записать fault, exact cleanup других собственных SDK/receipts продолжается; endframe pending work чужого implementer сохраняется. Native EOF/typed/global callback census без registry resets.
9. Two cancel/dispose/reload/Play-exit cycles, включая domain reload disabled: no stale key/callback/container; double disposal safe. Play exit подтверждает native boundary, но не заменяет live same-map packet.

Все cases сохраняют exact owned GO/component refs и scene handles, native Unity-null/dirty/settings before/after, UID dictionary entries и typed membership, captured StateSave implementer+component tuples и subscribed manager delegate multiset, startup/source fingerprints и cleanup failures. Reflection допустима в диагностическом readback, не runtime API. Нельзя использовать поздний пустой registry inventory как доказательство same-frame unregister или reset sets для PASS.
