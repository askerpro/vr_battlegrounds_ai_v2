# Оптимизация обнаружения MCP-инструментов

Пользователь одобрил 2026-10-03: стабильный MCP 10.2.0 из коммита
`30d22075093d1d35dfb0091c1c7550e9ad948577` и перенос второго upstream-фикса
из beta. Работа выполняется последовательно в очереди общего редактора.
Готовая работа сохраняется scoped-коммитом по прямому требованию пользователя.

## Контракт

- CommandRegistry использует TypeCache из stable 10.2.0; ToolDiscoveryService —
  тот же путь по upstream beta. Полных обходов AppDomain в обнаружении нет.
- ResourceDiscoveryService уже использует TypeCache и не меняется.
- Каталог и параметры существующих инструментов/ресурсов сохраняются. Расширения
  поддерживаются через обычные импортированные Unity assemblies, индексируемые TypeCache.
- Порядок дубликатов инструментов совпадает у метаданных и реестра; повреждённый
  пользовательский атрибут не прерывает регистрацию остальных обработчиков.
- AssetImportWorker не запускает обнаружение. Имена, параметры и обработчики команд
  остаются совместимыми.
- Не загружать бинарные записи Profiler: предыдущий вызов LoadProfile привёл к крашу.
- Обновление пакета и компиляция — под существующим Unity lock, вне человеческого Play Mode.
