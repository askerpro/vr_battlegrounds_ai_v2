# План реализации адресного стенда Play Mode

> Для исполнителя: использовать `superpowers:executing-plans`, выполнять пункты последовательно в собственном worktree. Пользователь поручил реализацию 2026-10-07; дополнительное разрешение на этот срез не требуется.

**Goal:** агент через MCP управляющего редактора выбирает одного участника Play Mode, создаёт только у него временный несетевой маркер и получает адресный ответ.

**Architecture:** один координатор управляет участниками текущего запуска. Участники регистрируют отдельный IPC-обработчик, проверяют идентификаторы запуска/участника/сессии и не запускают сеть самостоятельно. Производственный профиль и идентичность сохраняют одного владельца; временные значения живут только в области стенда.

**Tech Stack:** Unity 6000.4, UnityEditor.MPE.EventService, Mirror, обычный execute_code MCP, локальный .NET 9 харнесс без NuGet.

**Spec:** локальный `Docs/tasks/report/vr-test-stand/next-probe-contract.json`; девять критериев A1–A9 перенесены в этот план.
