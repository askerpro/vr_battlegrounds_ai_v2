# Реализация калибровки прицелов

> Исполнение: `superpowers:executing-plans`, последовательно в общем checkout Unity.

Основание: [дизайн](weapon-sight-calibration-design.md). Согласовано 2026-10-04:
общая дистанция сведения по умолчанию 15 м, адресная настройка оружия/прицела;
ближняя стрельба преимущественно интуитивная. Ограничение ≤2 см на всём интервале
от дула отменено. Виртуальная точка оптики соответствует выбранному сведению,
а не фиксированным 20 м при другой настройке. Арена ограничена 20 м.

## Первый срез: конфигурация и Audit

- [x] `Assets/Scripts/Weapons/Sights/WeaponSightCalibrationSettings.cs`: общий конфиг, default=15, допустимая дистанция (0,20] м; без singleton и управления выстрелом.
- [x] `WeaponSightCalibrationProfile.cs` рядом: WeaponInfo, SightId, trigger/shot indices и необязательная custom distance. Разрешение дистанции через явно переданный общий конфиг.
- [x] `Assets/Editor/VR_Battlegrounds/Weapons/Calibration/WeaponSightAuditReport.cs`: полная схема отчёта без Unity object references.
- [x] `WeaponSightAudit.cs` рядом: AssetDatabase resolver всего реестра, исходные GUID/localFileID/path, dependency hashes, TRS, спуски/shotTypes, меши и материалы. Отчёт в `tmp/weapon-sight-calibration/`. Имена деталей — только подсказки, все записи до разметки NeedsReferenceReview.
- [x] Создать общий конфиг и выполнить Audit под замком; проверить весь реестр, повторяемость и неизменность входных ассетов, отказ при недопустимой дистанции. Editor и Android-компиляция.
- [x] Обновить дизайн, README и CHANGELOG фактическими результатами.

Проверено: inventory 20/20, 22 shotTypes, 253 записи геометрии; 18 native-проб,
детерминированные повторные снимки и неизменные dependency hashes 42 входных ассетов.
Независимое read-only ревью первого среза: замечаний нет.
Первый срез не калибрует оружие. Последующие измерения описаны ниже.

Из-за текущих незакоммиченных правок и общего редактора используется текущий checkout:
сохраняются только новые адресные файлы; исходные префабы и чужие правки не меняются.
До освобождения Unity новые исходники подготавливаются в `tmp/weapon-sight-calibration/staged/`.
Тесты принятой игровой механики не создаются до проверки пользователем по AGENTS.md;
этот срез проверяется native-пробами конфигурации и read-only Audit.

## Второй срез: геометрия, визуальный выбор и прототип оптики

- [x] `SightVisualReview.cs`: read-only vertices/triangles/provenance и изолированные виды 20 оружий/13 доноров (99 PNG); верхний вид исправлен для длинных моделей.
- [x] `SightGeometrySolver.cs`: double-модель текущей/предложенной линии и непрерывное смещение; physicalApproval остаётся false. 12 диагностических проб и Android PASS.
- [x] Разметить черновые R/F Viper/SRM12 по индексам действительных вершин; сохранить source hashes, кривые и предложения +3.0399/−5.3231 мм. Приёмка References и механизмов пока открыта.
- [x] Найти отсутствующие прицелы: MKR9 и SniperRifle. Подготовить родной комплект MKR9; для SniperRifle пользователь выбрал только модульный комплект SRS/SRM12. Пять штатных деталей, эскизы двух переходных площадок и отдельный материал под SniperRifle; исходные префабы неизменны. Дополнительный Mk14 не нужен.
- [x] `WeaponOpticView.cs` и `FiniteFocusReticle.shader`: только визуальные параметры конечной точки M+forward×Z, eye выбирает URP shader.
- [x] `SightPrototypeReview.cs`: изолированный TR15, пять смещений монокамеры, новая точка 5/5 против surface baseline 0/5; отказ для неприменённой/устаревшей дистанции и сохранение чужого MPB. Editor/Android PASS.
- [x] Независимое read-only ревью второго среза; замечаний нет. [Визуальный пакет](weapon-sight-calibration-review.md) документирует доказательства и пределы.

Runtime-компонент пока не установлен в игровой префаб. Проверка дистанции ещё не
реализует полный fingerprint будущего Approved/Apply. Actual SDK shots/replay и Quest
stereo не проверялись; ни один результат не считается общей калибровкой реестра.

## Осталось выполнить

1. References: визуально принятые R/F, апертура, механизмы регулировки и полный профиль происхождения точек; Viper, SRM12, TR15 как первый roundtrip.
2. Feasibility/Candidate: применять double-геометрию к принятым References и допустимым DOF. Numeric budget реальных мешей до PASS; физически допустимые детали/крепления для Viper/SRM12 и доноров.
3. VisualReview/Approved/Apply: адресное принятие hash, проверка актуальности конфигурации и источников; изменение дистанции инвалидирует старый кандидат. Без автоматического применения при редактировании настройки.
4. Optics: принять/подключить проверенный материал XPS2, проверить per-eye virtual focus на выбранной Z без изменения выстрела. SniperRifle использует выбранный механический комплект SRS; рабочее увеличение для него не требуется.
5. Verify: actual SDK shot, pellet axis/replay, весь реестр, стерео Quest и визуальная приёмка. Полную калибровку не объявлять по compile/Audit.
