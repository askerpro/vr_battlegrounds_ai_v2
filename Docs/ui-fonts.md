# Шрифты UI (TextMeshPro)

Весь текст UI — TextMeshPro. Шрифт проекта — **Roboto Condensed** (Regular + Bold),
статический атлас с латиницей и кириллицей. Он же шрифт TMP по умолчанию и глобальный
fallback.

| Что | Где |
|---|---|
| Исходники `.ttf` + лицензия OFL | `Assets/Art/Fonts/RobotoCondensed/` |
| Font asset (атлас + таблица глифов) | `RobotoCondensed-Regular SDF.asset`, `RobotoCondensed-Bold SDF.asset` там же |
| Утилита сборки и применения | `Assets/Editor/VR_Battlegrounds/UI/ProjectFontTool.cs` |
| Шрифт по умолчанию, глобальный fallback | `Assets/ThirdParty/TextMesh Pro/Resources/TMP Settings.asset` |
| Тест покрытия глифами | `Assets/Tests/EditMode/UI/UiFontCoverageTests.cs` |

## Как TextMeshPro рисует текст

TMP не рисует буквы из `.ttf` напрямую. Он работает с **font asset**, внутри которого:

- **атлас** — одна текстура (у нас 2048×2048), на которую заранее разложены все
  буквы шрифта;
- **таблица глифов** — какой символ в каком прямоугольнике атласа лежит.

Буквы в атласе хранятся как **SDF** (signed distance field): пиксель хранит расстояние
до края буквы, шейдер восстанавливает по нему чёткий контур при любом масштабе.
Поэтому текст на планшете не расплывается, когда его подносят к лицу, а обводка и тень
получаются почти бесплатно.

**Нарисовать можно только то, что есть в атласе.** Для отсутствующего символа TMP идёт
по цепочке:

1. font asset самого текста;
2. его личный список `Fallback Font Assets`;
3. глобальный список fallback в `TMP Settings`;
4. шрифт по умолчанию из `TMP Settings`.

Не нашёл нигде — рисует пустой квадрат. Со стороны это «кракозябры».

### Static и Dynamic

| Режим | Как работает | Цена |
|---|---|---|
| **Static** | Набор символов запекается в редакторе один раз | Символ вне набора не нарисуется |
| **Dynamic** | Держит ссылку на `.ttf`, дорисовывает буквы по требованию | В редакторе `.asset` переписывается при каждом новом символе — вечный шум в git |

**В проекте — только Static.** Dynamic-шрифт уже однажды сломал меню (см. ниже).

## Почему не fallback, а явный шрифт

Стандартная поставка TMP Essentials: `LiberationSans SDF` статический (только латиница,
250 глифов) + `LiberationSans SDF - Fallback` динамический для всего остального.
Динамический файл постоянно висел изменённым, и коммит `427dc5b` выкинул его из git
(с добавлением в `.gitignore`). Ссылка из `LiberationSans SDF` на fallback осталась
висеть в пустоту, и **вся кириллица меню пропала** (UI-01). Шрифты SlimUI
(`RUBIK-*`, `LATO-*`) тоже статические и тоже только латиница.

Fallback решал бы проблему формально: латиница рисовалась бы одним шрифтом, а кириллица —
другим. Поскольку меню почти целиком на русском, визуально это был бы fallback-шрифт.
Поэтому шрифт назначен явно, а fallback оставлен только страховкой.

Висящая ссылка в `LiberationSans SDF` безвредна: TMP пропускает пустые элементы
fallback-таблицы. Строку в `.gitignore` не удалять — она не даёт вернуть в репозиторий
динамический файл.

## Как применять шрифт

### Новый текст

Ничего делать не нужно: `Create → UI → Text - TextMeshPro` получает шрифт по умолчанию,
то есть `RobotoCondensed-Regular SDF`.

### Жирный текст

Поставить стиль **Bold** (кнопка **B** в инспекторе TMP или `<b>...</b>` в тексте).
В таблице начертаний Regular (`Font Weights → Bold (700)`) прописан
`RobotoCondensed-Bold SDF`, так что рисуется настоящий Bold, а не искусственное
утолщение шейдером. Назначать Bold-ассет в поле `Font Asset` напрямую не нужно.

### Существующие префабы на старых шрифтах

`Tools → VR Battlegrounds → UI → Шрифт — применить к UI-префабам`.

Проходит по `Assets/Prefabs/UI`, заменяет шрифт у всех TMP-текстов, сбрасывает материал
на родной (материал старого шрифта ссылается на чужой атлас) и переводит бывшие
`*BOLD*`-шрифты в стиль Bold. Тексты вложенных префабов правятся в файле самого
вложенного префаба — внешний override'ов не получает. Префабы, где менять нечего,
не открываются: пересохранение дописывает в файл поля сериализации новой версии Unity.

Из кода и агентом: `VrBattlegrounds.EditorTools.ProjectFontTool.ApplyToUiPrefabs()`.

### Текст в сцене, а не в префабе

Утилита сцены не трогает. Руками: в инспекторе TMP поле `Font Asset` →
`RobotoCondensed-Regular SDF`, `Material Preset` → `RobotoCondensed-Regular SDF Material`.

### Обводка, тень, свечение

Не редактировать общий материал `RobotoCondensed-Regular SDF Material` — он у всех
текстов один. Создать копию материала рядом с ассетом (имя должно начинаться с имени
ассета, иначе TMP не покажет его в `Material Preset`) и выбрать её в `Material Preset`.

## Как добавить символ

Набор символов — свойство `ProjectFontTool.CharacterSet`: ASCII, Latin-1, кириллица
`U+0400–U+045F`, типографика (`– — « » „ “ • … № ₽ ™ −`).

1. Дописать символ или диапазон в `CharacterSet`.
2. `Tools → VR Battlegrounds → UI → Шрифт — пересобрать атласы`.
3. Если в консоли `[ProjectFontTool] В ... нет символов: U+XXXX` — в самом `.ttf` этого
   символа нет. Стрелок `←↑→↓` в Roboto Condensed нет, в UI писать `<-` / `->`.

Пересборка идёт **на месте**: GUID ассета сохраняется, ссылки из префабов и
`TMP Settings` не рвутся. Удалять `.asset` перед пересборкой нельзя — новый GUID
оторвёт шрифт у всех текстов.

Каждая пересборка — два файла по ~8,5 МБ (текстура атласа сериализуется в YAML).
Пересобирать только когда меняется набор символов.

## Проверка

`UiFontCoverageTests` (EditMode):

- `AllUiPrefabTexts_HaveGlyphsForEveryCharacter` — каждый символ каждого TMP-текста
  в `Assets/Prefabs/UI` есть в его шрифте или в цепочке fallback. Проверяется
  именно запечённое (`tryAddCharacter: false`), а не то, что dynamic-шрифт дорисовал бы.
- `DefaultTmpFont_CoversCyrillic` — шрифт по умолчанию содержит всю кириллицу, `№`, `«»`, `—`.

Тест не видит текст, который выставляется из кода в рантайме (имена карт, игроков).
Такой текст покрывается набором символов шрифта по умолчанию.

## Параметры атласа

| Параметр | Значение | Почему |
|---|---|---|
| Sampling point size | 80 | Чёткие края на планшете вблизи |
| Padding | 8 | ~10% от размера — хватает на обводку и тень |
| Atlas | 2048×2048, один на начертание | ~300 глифов влезают без multi-atlas |
| Render mode | SDFAA | Стандарт TMP |
| Память на Quest | 4 МБ на начертание (Alpha8) | Два начертания — 8 МБ |
