# Решения пользователя по оружию

Журнал: новое решение — новая строка с датой. Перед вопросом пользователю проверь, нет ли ответа здесь.

## Механика

| Дата | Тема | Решение |
|---|---|---|
| 2026-10-07 | Учёт расходится | Если состояние может разойтись — значит архитектура кривая; нужен единый источник, а не сверка (→ C2) |
| 2026-10-07 | Число патронов не сошлось | Непредвиденная ситуация: `GameLog.WeaponSystem.Error`; поведение — чтобы игрок мог продолжать играть |
| 2026-10-07 | Расхождение ревизий | Серверная поправка (В-Л6); сбой уведомлений — Error, стрельба не блокируется (В-Л5) |
| 2026-10-07 | S1 | Ствол без анимации «пустого»: последний выстрел — обычная анимация выстрела |
| 2026-10-07 | S2 | Спуск в паузе между выстрелами — отрицательная вибрация + искусственный звук отказа `UI_Error_Subtle_Deep_stereo` (не щелчок), без подсказки. Автомат: нажатие в паузе — выстрел по её окончании (решение владельца, сообщено) |
| 2026-10-07 | S4 | Отпущенная помпа FABARM остаётся на месте; ось профиля Spring/Stay |
| ~2026-10-08 | Открытый Action | Неоттянутый и недовозвращённый Action — одна проблема: «не дослан» → щелчок + вибрация + подсказка (подсветка) |
| 2026-10-09 | Частичный ход | Отдельное событие `ActionReturnPartial` (под будущий отклик «перезарядка не выполнена»); звук тот же, что возврат без подачи |
| 2026-10-07 | Смена магазина при открытом затворе | Нужен новый цикл |
| — | Звук «патроны кончаются» | Слой к выстрелу на последних N, слышат все (и противники), порог в профиле ствола |

## Отклик (звук, вибрация)

| Дата | Тема | Решение |
|---|---|---|
| 2026-10-09 | Снайперская категория | Четвёртая категория «снайперская винтовка» (SniperRifle = AX-50, SRM12 = Desert Tech SRS — не дробовик): патрон/гильза и звук затвора — дефолт категории, не оверрайды ствола |
| 2026-10-09 | use-context: отдача корня NPC | SDK-интерфейс `IUxrFirearmRootRecoilPolicy` реализует `WeaponEquipmentBinding` (владелец bots-fix), `AllowsRootRecoil => !IsActive`. Активный claim запрещает root recoil при потерянном owner и выключенном WeaponSystem. SDK-порт и его потребление — weapon-system; adapter binding согласуется через хаб |
| 2026-10-09 | Дефолты | По категориям: автомат, дробовик, пистолет; ствол — только оверрайды; подстановка в исполнителе; сборщик не копирует. Точнее категории — позже |
| 2026-10-09 | Нарезка звуков | Постоянный конвейер в проекте (`Tools/Audio`), проверено на SRM12 |
| 2026-10-07 | Вибрация | Отдельная задача haptics-system пишет под WeaponSystem. Карман вибрирует всегда, старт 10 % (настраиваемо). Отдача — у владельца архитектуры оружия (WeaponSystem). Выключателя позитивных подсказок нет. Гибель — максимум 1,5 с. OpenXR не переходим |

## Захват

| Дата | Тема | Решение |
|---|---|---|
| 2026-10-13 | Инерция оружия в руке | Отставание оружия от контроллера (сопротивление SDK, патч 73: у PPK ~3,8 см при 1 м/с) допустимо, пока виртуальная кисть идёт вместе с оружием (`KeepGripsInPlace`). Недопустим видимый рассинхрон оружия и виртуальной кисти. Сопротивление стволов не меняем |
| 2026-10-09 | Перехват второй рукой | Запретить для огнестрела, но оставить возможность быстро включить: `ManipulationConstraints.AllowHandTransfer` (класс ограничений манипуляции, имя без привязки к огнестрелу) |
| 2026-09-29 | Пистолет за поддержку | Лежащий пистолет берётся только за основную рукоять (`SupportGripRequiresMain`) |
| 2026-09-27 | Пистолет крутится от второй руки | Поза по основной руке (`MainGripAimLock`) |

## Арсенал и патроны

| Дата | Тема | Решение |
|---|---|---|
| 2026-10-08 | Охват | Весь арсенал переводится на новый поток, не только дробовики |
| 2026-10-09 | Револьвер и дробовики | В будущем — ручное заряжание и опциональная «пачка» (спидлоадер/коробка); выпадение барабана целиком допустимо для прототипа |
| 2026-10-09 | Вылет | Живой патрон при извлечении и гильза при выстреле — только визуал, видят все; слой Ignore Raycast (без нового слоя) |
| 2026-10-09 | Вылет снайперских | Снайперский патрон, если есть модель (взят 7.62×51 Mk14 под .308 и гильза .338 Kinemation); если модели нет — оставить как есть |
| 2026-10-09 | Гильза у ручного цикла | Признак стреляной гильзы в учёте SDK (SDK-патч), а не память машины — отдельный шаг после основной части ejection |
| 2026-10-09 | ejection-manual: детали | Бот на Automation выбрасывает гильзу; расхождение признака при replay — строгая проверка; правило гильзы на Shot (FireMode ≠ Manual) не меняется; риск `_last` — отдельной правкой; патч — только в журнале задачи (`tasks/weapon-system/ejection-manual.md`) |

## Прицелы

| Дата | Тема | Решение |
|---|---|---|
| 2026-10-11 | Приоритет | Калибровка всего оружия — главная задача; ejection-manual и прочее второстепенно |
| 2026-10-11 | Эталон | TR15 `· Sight Review` (коллиматор XPS2, конечный фокус 15 м) откалиброван идеально; его прицел переходит в основной TR15 |
| 2026-10-11 | Способ | Остальные стволы сводятся по родной механике (целик/мушка), не заменой на коллиматор |
| 2026-10-11 | Порядок | Чем быстрее правка и результат, тем выше приоритет ствола |
| 2026-10-11 | Дубли | Копии `*_SightReview` убрать со стены арсенала лобби сейчас; сами копии остаются рабочим материалом до переноса в оригиналы |
| 2026-10-12 | Подвижные детали | Регулировочные детали прицела (столбик мушки, блок целика) отделяются в отдельные объекты, включая вшитые в корпус (AK-105, Mk14, Viper, R08 — разделение в сборщике, повторяемое); MX68 и комплект TR15 — как доноры |
| 2026-10-12 | Высота | Рамки только в поднятом рабочем положении, наклон ради высоты недопустим; высоту посадки задаёт планка, сведение по высоте — ходом столбика |
| 2026-10-12 | Автосведение | Точка привязки подвижной детали стоит ровно на точке прицеливания (F — вершина мушки, R — центр отверстия/прорези); сведение = решатель двигает столбик по высоте и блок целика вбок, чтобы линия R→F прошла через ShotSource + 15 м. Статические объекты, не skinned (дешевле на Quest) |
| 2026-10-12 | Только высота | Поправка по горизонтали по игре не нужна: сведение только вертикальным ходом одной подвижной детали; боковое расхождение инструмент показывает, но не исправляет. MX68 — как у реального (горизонтали нет) |
| 2026-10-12 | FABARM | У дробовика FABARM SDASS (только бусина) ничего не калибруем |
| 2026-10-12 | Remington 11-87 | Калибруем, если получится: V-целик и мушка-лопатка, подвижная — передняя лопатка по высоте; не выйдет — оставить как есть |
| 2026-10-12 | PPK | Прицел — одна оболочка с затвором; оставить без подвижной детали, «Свести» только показывает ошибку (+14,7 мм на 15 м) |
| 2026-10-12 | Uzi | Мушка двигается целым островом вместе с защитными ушками (сдвиг ~0,9 мм), без разреза геометрии |
| 2026-10-12 | Только инструменты | Текущая задача — инструменты калибровки; финальная калибровка стволов (запись таблицы, применение к префабам, встраивание разделителя в сборщики) — отдельной задачей |
| 2026-10-12 | Ход TR15 | Столбик мушки комплекта TR15 в модели выкручен выше целика (~4,4 мм): ход вниз 8 мм, вверх 3 мм (сведение AR-15 на 15 м требует −5,6 мм) |
| 2026-10-12 | Ход родных | Mk14 — диоптр вверх до 8 мм (нужно +6,67), Viper — целик вниз до 4 мм (нужно −3,07); остальные ±3 мм |
| 2026-10-12 | Uzi сбоку | Мушка смещена на 0,4 мм вбок — 3,25 см на 15 м; оставить как есть, горизонтальную поправку не делать |
| 2026-10-12 | Посадка | Комплект — один объект на планке (корень Rear + Front); пользователь ставит его на планку, раздвигает половины вдоль планки и жмёт «Свести» |
| 2026-10-20 | Посадка в паз | Любой комплект (механика, коллиматор) садится на планку ствола как настоящее крепление: зубцы планки входят в паз (канал) основания комплекта, упор — в поперечный паз планки; не сверху на зубцы и не над планкой. Правило общее для всех посадок |
| 2026-10-20 | Стенд | Действующий подход — стенд Sight Auto-Zero (варианты SightKit_MX68, SightKit_TR15, «Родной прицел»): у ствола со своим прицелом целик/мушка отделяются от корпуса (разбор Blender → SightSplit), стволу без прицела ставится готовый комплект. Ручной стенд `WeaponSightManualCalibration` и подход 2026-10-04/06 (маркеры, копии Sight Review, доноры) устарели |
| 2026-10-20 | Уборка | Старый ручной стенд удаляется в задаче `weapon-sight-calibration` вместе с копиями `*_SightReview` и их записями; сохраняется только витрина прицелов и аксессуаров (основа будущего модуля аксессуаров) |
| 2026-10-20 | Без копий | Любая правка оружия либо применяется к игровому префабу, либо отклоняется. Копия допустима только до коммита — для сравнения side by side во время проверки; в коммите копий быть не должно |
| 2026-10-20 | Стенд оружия | Единый стенд «Настройка оружия» из модулей: прицел (Sight Auto-Zero), аксессуары, баланс/паспорт (`WeaponInfo`), раскладка слота (ссылка на `ArsenalLayoutAuthoringStand`). Каждый модуль пишет в свой источник данных; префаб собирает из записей один писатель, повторяемо. Первым модулем — калибровка, остальные — следующими задачами |
