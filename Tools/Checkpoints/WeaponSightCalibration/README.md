# Исходные дельты WIP прицелов

Пакет сохраняет части работы, уже применённые в общем рабочем дереве, когда базовые
арсенальные файлы другой задачи ещё не находятся в HEAD. **Не применять повторно
в текущем workspace.** Полные текущие файлы и базы находятся в локальном отчёте
`Docs/tasks/report/weapon-sight-calibration/checkpoint/`.

- `lobby-range.patch` — адресные изменения щитов, мониторов, контейнера ShootingRange
  и удаления двух станций; база — сохранённый Lobby до нашей игровой проверки.
  Изменения PhysicalArenaLayout/OpeningBlocks/MapReferee других задач исключены.
- `full-demo.patch` — пять проверочных записей поверх ранее подготовленного FullDemo.
- `arsenal-builder.patch` — адресные поправки фиксированных количеств к проверочной
  конфигурации; полный чужой авторинг не включается в этот коммит.

Базовые SHA-256 нормализованного UTF-8/LF текста, выбранные объекты и проверки
дельт фиксируются в `bases.json`. Для проверки база нормализуется тем же способом;
рабочие файлы Unity не переписываются.
Если база в другом checkout отличается, сначала интегрировать исходный арсенальный
срез, затем проверить дельту без записи через `git apply --check`. Не использовать
`--reject`, слепой Apply или полную замену пользовательской сцены.

Состояние и порядок продолжения: `Docs/tasks/weapon-sight-calibration-handoff.md`.
