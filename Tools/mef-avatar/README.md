## Как FBX попал в Blender

`bpy.ops.import_scene.fbx` (старый Python-импортёр) на ASCII FBX падает: *"ASCII FBX files are not supported"*.
Конвертации не было: в Blender 5.2 есть встроенный C++-импортёр на ufbx — `bpy.ops.wm.fbx_import(filepath=…, use_anim=False)`,
он читает ASCII напрямую. Экспорт — обычным `bpy.ops.export_scene.fbx` (бинарный FBX 7.4).
9 текстур MEF (наручники, турникет, кобура, IR-патч, stencil) лежат только в `…/FBX/Raider/Textures` — перепривязка по имени файла.

  «сохранённых» вершин. Финал: стыковые объекты (одежда, перчатки, балаклава, очки, наушники, лицо, предплечья) — запас 4 см
