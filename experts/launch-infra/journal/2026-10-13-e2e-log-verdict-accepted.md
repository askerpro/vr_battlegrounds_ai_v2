# Вердикт e2e по логам принят: ошибки всех процессов роняют прогон, известные дефекты видны с владельцем

Принято пользователем 2026-10-13 (этап `quest-perf-pipeline/e2e-log-verdict`, контракт `quest-device-run` r5).

- Каждый процесс собирает Error/Exception/Assert в результат (`E2ELogCapture`; Log/Warning — без аллокаций, условие
  performance). Ключ группировки нормализует числа и GUID. Дирижёры (`Run-E2E.ps1`, `Run-QuestE2E.ps1`) сводят
  `log-verdict.json`, ищут нативные падения в сырых логах; enforce по умолчанию, `-LogVerdict report` — только отчёт.
- Решение по шуму (установка пользователя «ошибки исправлять, не фильтровать»): `known-noise.json` — только
  доказанно безвредный шум; известные дефекты — `kind=defect` с owner/ticket, прогон с ними остаётся red.
- Первые реальные прогоны на свежем плеере (43b3ab5c) нашли две давние ошибки при зелёных сценариях:
  утечка арсенала при выгрузке сцены (gameplay `arsenal-unload-teardown`, симптом у manipulation 6032/6073/6079) и
  `UpdateTeleportState` для неизвестных серверу компонентов рук (network `teleport-state-unknown-target`, 6054).
- Не проверено: настоящий прогон `Run-QuestE2E` на шлеме (только фикстуры) — сделать при свободном шлеме.
- Смок-тест серии матчей пишет gameplay; launch-infra готовит каркас `e2e-smoke-kit` (5863/5869/5880, network 5886).
