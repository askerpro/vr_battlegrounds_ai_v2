# Один автор синхронизируемого действия: StateEventAuthority и патч SDK 23

`cc3d64de0f6f7f206366117da3206b38d9417396`. Выстрел давал две пули и двойной урон: UXR пересчитывал выстрел
чужого игрока и одновременно синхронизировал `Shoot`. Патч SDK 23 — выстрел решает только стрелок, остальные
воспроизводят по событию. `StateEventAuthority`: событие предмета в руке шлёт только автор держащего аватара,
отброшенное считается. Тот же класс: отпускание предметов умершего, перезарядка затвором, `IsGrabbable` арсенала.
Правило «один автор» вошло в корневые правила.

Проверено автором: Quest 3 с выделенным сервером — пистолет даёт одну пулю; `RemoteShotReplayTests`,
`StateEventAuthorityTests`; EditMode 480, красные только прежние `AvatarLoadoutTests`.

Источники: коммит выше; `Docs/UltimateXR/known-issues.md` Issue 23; `Assets/Scripts/Network/StateEventAuthority.cs`.
