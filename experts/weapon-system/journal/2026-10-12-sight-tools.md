# Инструменты автосведения прицелов влиты; калибровка стволов — отдельной задачей

Решения пользователя 2026-10-11/12 — `Docs/weapons/decisions.md` «Прицелы». Коллиматор TR15 перенесён из
эталона в основной TR15 (`5fc16206`, builder теперь сохраняет Mirror `_assetId`). Механика: подвижна одна деталь,
только по высоте; pivot на точке прицеливания; «Свести» считает сдвиг аналитически.

Влито `a3b06c63`: комплекты TR15/MX68 из пака (нарезка в Blender), окно Sight Auto-Zero с режимами «комплект на
планке» и «Родной прицел» (разделитель SightSplit по спецификациям островов 11 стволов). Ход: TR15 −8/+3, Mk14 +8,
Viper −4, остальные ±3 мм. PPK — только показ ошибки, FABARM не калибруем, Uzi сбоку 3,25 см оставлен.

Дальше (отдельная задача): встраивание разделителя в сборщики, запись таблицы и применение к префабам по стволам,
проверка в шлеме. Пресет арсенала без дублей ждёт gameplay (отпечаток каталога зависит от EOL).
