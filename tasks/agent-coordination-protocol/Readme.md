# Координация агентов

Обновлено: 2026-10-09. Владелец: `coordination-maintenance`, Codex,
worktree `F:/UnityProjects/Vr_Battlegrounds_ai`.

## Цель

Агенты в отдельных worktree согласуют архитектуру до конфликтующей реализации,
сохраняют независимую параллельную работу и вливают принятые изменения по зависимостям.
Человек видит актуальный прогресс без поиска в чатах.

Контракты и пересечения проверяются при допуске; согласование остающихся
зависимостей блокирует отдельные этапы, не общую очередь.

## Решение

Единственный авторский план — соседний [plan.json](plan.json). Хаб хранит ссылки,
подтверждённые ревизии/ACK, допуски и очередь. Изменение локального плана требует
обновить регистрацию; действующий допуск не расширяется автоматически.
Задача пишет материалы и отдельные записи изменений в собственной папке.
Общие индексы строит координатор. В Docs переносится принятая текущая архитектура
отдельным этапом; постоянные утилиты обслуживаются в Tools.
Общение всех агентов — через inbox. Штатное сообщение только уведомляет прочитать inbox;
между вендорами уведомление переносит человек. ACK не заменяет согласование контракта.
