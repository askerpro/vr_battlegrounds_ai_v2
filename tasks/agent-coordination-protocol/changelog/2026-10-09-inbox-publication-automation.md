# Видимость inbox и автоматическая публикация

Изменения в agent-infra: адресные pending-события выдаются прежде старой broadcast-истории;
свежий опрос не использует page cursor предыдущего опроса. Добавлены метаданные пагинации,
стабильный snapshot cursor и lookup --event. Чтение не делает ACK.

request-base создаёт идемпотентный служебный тикет общей FIFO. Исполняет его системный
процесс pinned runtime, без LLM и без аренды у инициатора. Используется существующее
переключение, readiness, журнал и recovery; backwards publish запрещён. Результаты
адресно публикуются в inbox с защитой от дублей. Stop не допускает новый тикет, deploy
ждёт старый процесс до замены runtime; resume сохраняет явную остановку оператором.

watch-inbox — ограниченный read-only помощник штатного Monitor, а не служба доставки.
Межвендорное уведомление остаётся ручным; idle-пробуждение существующего Codex не обещано.

Итоговый полный прогон: 303 OK, 6 skip. Runtime 4a85f76 установлен, техническая пауза
снята, системный исполнитель запущен. Проверочный production тикет №250 ожидает
