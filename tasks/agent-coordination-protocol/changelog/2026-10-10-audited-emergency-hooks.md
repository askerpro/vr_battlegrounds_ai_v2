# Аварийный PreToolUse с аудитом

Пользователь разрешил владельцам временно снимать локальные hook-блокеры под его
ответственность, с журналом команд и статистикой для сопровождающего. Source закреплён
в отдельном agent-infra: `9e5fa445a2655c6a45823a22a653f978cfaa8cae`.

Исправлен ложный запрет локального `git stash push`. Emergency включается только для
своей задачи/checkout, с причиной и TTL 1–3600 секунд; доступны on/off/stats/log.
Каждая активная попытка имеет обычное решение hook, итог допуска и redacted tool input.
Контрольные события доставляются сопровождающему; сами вызовы остаются в SQLite-аудите.
Client/model справочные. Worker/proxy/CLI guards, ownership и публикация сохраняются.

Финальные emergency tests:23/23; выбранные132/132 проверены до последней адресной правки
Git target/redaction. Независимое ревью закрыло8 адресных guard-проб и redaction-проверки.
Интегрированные source файлы побайтно совпадают с reviewed commit9735166. Полная baseline
была прервана и не заявляется PASS. Runtime rollout требует отдельного preflight, backup
и проверки живого hook; игровой приёмки этот выпуск не содержит.
