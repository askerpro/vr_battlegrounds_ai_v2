# Нативная адресация задач

Дата: 2026-10-09. Статус: runtime2416598 установлен, pause=false, publisher42320
работает. Полный UV-набор: 332 passed, 1 symlink skip, 587,815 с; ревью без блокеров.
Владельцы публикуют адреса сами, принадлежность чужих сессий не угадывается.

## Причина

task-id, UUID плана и native endpoint различны. Имя Claude-сессии может повторяться;
старое имя из переписки не доказывает принадлежность текущего endpoint.
Inbox остаётся каноническим; native сообщение лишь уведомляет о task-id/event_id.

## Решение

Маршрут хранится в hub settings отдельно от plan.json/контрактов/permit.
Владелец из своего зарегистрированного checkout публикует client-derived адрес,
канал и expected epoch. CAS предотвращает потерю обновлений; clear сохраняет tombstone.
Дубли одного client/channel/address разных задач запрещены. Подмена owner/client/worktree
в старом binding ведёт к manual. Публикация не меняет ревизию плана или running stage.

Claude использует точный name [ref] из собственной первой строки ListAgents.
Сырой ref, имя без ref и UUID плана не используются. Подагент не публикует endpoint
principal от своего имени. Перед отправкой sender получает свежий полный ListAgents
и сверяет обе стороны: свой address и адрес получателя. Hub возвращает только candidate,
не подтверждает присутствие, доставку или прочтение. Произвольный TTL этого не исправляет.

Неизвестный/cleared/stale адрес, иной клиент/канал или неполный native discovery требуют
ручного уведомления человеком. Нельзя угадывать сессию или рассылать всем похожим именам.
Codex collaboration текущего дерева не является глобальным каталогом других чатов.

## Проверка и границы

NativeRoutes: 10/10; coordination: 97/97; независимое ревью без Critical/Important.
Это кооперативная проверка owner/checkout и адресов-кандидатов, не native authentication.
Реальная принадлежность weapon-сессии и доставка события720 не установлены. Новых
daemon, управляемых LLM-сессий, auto-send или provider adapters не добавлено.

Полный исследовательский отчёт: [reports/native-route-analysis.md](reports/native-route-analysis.md)
(локально, вне Git). Рабочие команды описаны в правилах координации после deployment.
