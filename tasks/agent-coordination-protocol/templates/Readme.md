# Формат папки задачи

Скопировать шаблоны в tasks/<task-id>/ своего worktree и заполнить реальные значения.
В plan.json заменить идентификаторы, worktree, base_sha, этапы и writes. Нулевой SHA
в шаблоне — placeholder, не принятая база. Не копировать шаблоны в общий хаб.

Readme.md — компактный живой обзор, до 400 слов. Рекомендуемые разделы:

1. Цель и мотивация — какой результат нужен и почему.
2. Статус — дата обновления, владелец, текущий этап, что готово и что блокирует.
3. Архитектурное решение — 2–5 ключевых фактов; предложения явно помечены как предложения.
4. План — короткие пункты с прогрессом; полный машинный план по ссылке plan.json.
5. Синхронизация — требуемые контракты/ревизии, зависимости и ожидаемые действия владельцев.
6. Проверка — только фактические результаты и границы доказательства; приёмка отдельно от тестов.
7. Следующий шаг — конкретное действие и его владелец.

В обзор не помещать JSON, сырой лог, историю обсуждения и неподтверждённые ACK.
Подробности по ссылке Details.md; локальные отчёты помечать как локальные.
Другому агенту сначала передавать Readme.md с веткой agents/status или SHA,
либо абсолютный путь в доступном локальном worktree.

Файлы: [Details.md](Details.md), [plan.json](plan.json), [changelog-entry.md](changelog-entry.md).
Временные утилиты — tools/, постоянные после проверки — Tools/<категория>/ проекта;
все generated/debug данные — reports/, вне Git. Учитывать их миграцию в writes этапа.
