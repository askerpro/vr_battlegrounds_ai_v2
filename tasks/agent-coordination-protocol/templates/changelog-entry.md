# Краткое название изменения

Дата: YYYY-MM-DD. Задача: task-id. Тип: feature/fix/sdk/docs/tool.
Статус: предложено/реализовано/проверено/принято/влито — только фактический.

## Результат

Проблема, новое поведение и причина решения — несколько предложений.

## Проверка

Что проверено, результат, границы и источник приёмки. SHA вливания — после вливания.
Для SDK — имя SDK и зарезервированный номер патча, изменённые точки и инвариант.
Для контракта — идентификатор и точная согласованная ревизия.

Сохранить как changelog/<YYYY-MM-DD>-<slug>.md в собственной задаче.
Общие журналы и индексы не редактировать.
