# Временные утилиты миграции

Это инструменты текущей задачи, не постоянный интерфейс обслуживания проекта.
Запускать из собственного корня проекта. Результаты пишутся в ../reports/ и не входят в Git.

- migration_progress.py — сравнивает registry с локальным инвентарём миграции.
- maintenance_probe.py — читает паузу, аренды и очередь брокера; ничего не разблокирует.
- review_migration_registry.py — читает планы/контракты, сохраняет подробности локально.
- migration_readiness.py — проверяет формат, область и привязку локального плана
  без изменения registry; полноту контрактов и LLM-перехват не подтверждает.
- smoke_deployed_runtime.py — создаёт изолированный Git-стенд в reports/ и проверяет
  развёрнутый runtime; live registry не изменяет, настоящий LLM-перехват не проверяет.
- prepare_migration_drafts.py — исторический генератор предварительных черновиков по
  старой доске; черновики не являются регистрациями, требуют проверки владельцами
  и не должны использоваться как полные актуальные планы после миграции.

Пример: python -X utf8 tasks/agent-coordination-protocol/tools/maintenance_probe.py
Некоторые чтения требуют доступа к общему runtime и .agent-state/.
