# Аудит AGENTS.md и первичных ссылок

Дата: 2026-10-08. Проверены AGENTS.md, семь файлов `.agents/rules`, стартовые хуки, основные `.claude/commands`, профильные рецепты, навигация Docs и контракты брокера/прокси. Большие продуктовые справочники проверены как маршруты чтения, а не как полный аудит игровой архитектуры.

## Главная причина

AGENTS.md занимал 50 417 байт. Стандартный лимит Codex project_doc_max_bytes — 32 КиБ. Граница первых 32 768 байт совпала с фактическим обрывом начального контекста на строке 278, «Матч» — то… . Последующие правила делегирования, терминала и документации не попадали в стартовые инструкции.

Источник: [официальная документация Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

Не все ссылки загружаются автоматически. SessionStart вставляет только часть terminal.md начиная с раздела редактирования; остальные большие документы агент открывает, следуя маршрутам чтения.

## Исправлено в этом срезе

- Корень переведён на английский и сокращён до 59 строк / 7 255 байт: уменьшение стартового файла примерно на 86% по байтам.
- Подробные действующие ограничения сохранены в `.agents/rules/project-workflows.md`; корень предписывает читать только нужный раздел.
- Два режима checkout/Unity и приоритет текущих правил над старыми процедурами указаны явно.
- Порядок работы с тестами сформулирован единообразно: существующие проверки и компиляция → приёмка изменённой механики → её закрепление тестами в той же задаче.
- Из маршрутов убрано требование читать целиком Docs/README и большие тематические справочники; вместо этого поиск и выбранный раздел.
- CLAUDE.md правильно описан как импорт @AGENTS.md, а не симлинк.
- В сохранённой процедуре стенда tmp/test-stand/live.json заменён на task reports; legacy-план записывает номер patch-reserve, а не выделяет второй номер вручную.

Локального tiktoken нет. Точное количество токенов и отдельный выигрыш от смены языка не измерялись; процент относится ко всей редакции и размеру файла.
