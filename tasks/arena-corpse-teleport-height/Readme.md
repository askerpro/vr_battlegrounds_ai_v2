# Арена: труп не на месте смерти, высота после телепорта

2026-10-24. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/arena-corpse-teleport-height` (схема «задача = агент»).

## Цель

Труп появляется точно на месте смерти игрока; после телепортов игрок стоит на полу (без улёта в небо или под землю).

## Этапы

Этапы и области записи — в [plan.json](plan.json). Заготовленный этап `work` пишет только в `tasks/arena-corpse-teleport-height/**`: перед `begin` объявите нужные пути (`writes`) и перерегистрируйте план (`register`).
