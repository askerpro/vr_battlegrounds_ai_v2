# Боевой состав арсенала карт и перебаланс оружия

2026-10-23. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/arsenal-combat-lineup` (схема «задача = агент»).

## Цель

На игровых картах доступен только боевой состав (TR15, Herrington, MKR9, SRM12, новая автоматическая винтовка дальнего боя, Viper, Revolver); в Lobby — весь арсенал. TR15 не убивает одним выстрелом в голову, Revolver дороже и медленнее, новая винтовка собрана, сведена и с кратным прицелом.

## Решения пользователя (2026-10-23)

- Новая винтовка — Barrett M82 из пака Low Poly Weapons VOL.2 (`sniper_03`, 1,24 м). Самозарядная, 240/мин, магазин 10, цена 3700, урон 55, спад 0,98.
- Кратность — камера прицела с малой RT (моно, только у глаза), ×1,75, сетка конечного фокуса поверх; бюджет +1 мс ovr_gpu p50 на Quest 3. Копия кадра URP отвергнута после разбора performance (2–5 мс GPU).
- Проверить, не дорог ли коллиматор XPS2 на TR15 (статический разбор — в Details, замер — вместе с камерой Barrett).
- Остальные стволы остаются в Lobby (`FullDemoArsenal`); Mk14 из боевого состава убран.

## Проверка в шлеме

1. Карта (любая игровая): на стене только 7 стволов боевого состава, Barrett — на перфопанели, помещается в слот.
2. Lobby: весь арсенал + Barrett.
3. TR15: выстрел в голову не убивает (−96), голова + нога убивает; в тело — 4 попадания.
4. Revolver: цена 1250, выстрел не чаще 3 в секунду, голова убивает.
5. Barrett: хват (по умолчанию — поз кисти нет), вторая рука на цевье, затвор отводится, магазин снимается/вставляется,
   кладётся в карман; два попадания в тело / одно в голову; отдача сильная.
6. Оптика Barrett: у глаза включается увеличение ×1,75, перекрестие на точке попадания на 15 м, край трубы затемнён;
   отводишь — обычное стекло. Комфорт картинки (моно, без двоения).
7. XPS2 TR15 — без изменений вида.
