# Боевой состав арсенала карт и перебаланс оружия

2026-10-23. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/arsenal-combat-lineup` (схема «задача = агент»).

## Цель

На игровых картах доступен только боевой состав (TR15, Herrington, MKR9, SRM12, новая автоматическая винтовка дальнего боя, Viper, Revolver); в Lobby — весь арсенал. TR15 не убивает одним выстрелом в голову, Revolver дороже и медленнее, новая винтовка собрана, сведена и с кратным прицелом.

## Решения пользователя (2026-10-23)

- Новая винтовка — `SniperRifleAuto` (AX-50 Auto): вид SniperRifle, поведение Mk14 (автомат), урон 55, спад 0,98, 240/мин, магазин 10, цена 3700. Barrett M82 (Low Poly) собран и снят: вид не подходит; код источника Low Poly оставлен.
- Прицел — призма пака Hands `Sight_08` ×2, сетка как у XPS2. Кратность — камера прицела с малой RT (моно, только у глаза), сетка конечного фокуса поверх; бюджет +1 мс ovr_gpu p50 на Quest 3. Копия кадра URP отвергнута после разбора performance (2–5 мс GPU).
- Проверить, не дорог ли коллиматор XPS2 на TR15 (статический разбор — в Details, замер — вместе с камерой прицела AX-50 Auto).
- Остальные стволы остаются в Lobby (`FullDemoArsenal`); Mk14 из боевого состава убран.
