# arsenal-generator — станции арсенала из пресета

## Цель и мотивация

Станция арсенала собирается из пресета карты на каждой машине одинаково: сменить ассортимент — поменять
пресет, а не пересобирать префабы и сцены. Сетевые ID слотов выводятся из ключа запуска карты, поэтому
сервер, клиент и поздний клиент получают одну станцию. Один формат станций, без авторского режима.

## Архитектурное решение

- Сборщик станции не знает геометрии: связывает пресет, сборщик слота (`ArsenalSlotBuilder`) и ряды корпуса
  (`ArsenalSlotRow`).
- Ряд знает точку, поворот, зазор и префаб слота; слот — свою ширину и раскладку по умолчанию; оружие может
  принести свою раскладку.
- Стиль арсенала — только внешний вид; пресет — порядок «оружие → ряд».

## План

1. `composer-presentation` — новый флоу, раскладки слота, миграция всех карт (принято, к слиянию).
2. `decorations` — корпуса каталога.
3. `prefab-preview` — превью в Prefab Mode.
4. `acceptance` — шлем, два клиента, поздний вход.
