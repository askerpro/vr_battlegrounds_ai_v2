# arsenal-generator — станции арсенала из пресета

Владелец — эксперт `gameplay` (передана от агента arsenal-generator 2026-10-11). Обновлено 2026-10-14 (передача
Claude → Codex). Машинный план — [plan.json](plan.json), план этапов — [plan.md](plan.md), анализ — [Details.md](Details.md),
миграция — [new-flow.md](new-flow.md).

## Цель

Станция арсенала собирается из пресета карты на каждой машине одинаково: сменить ассортимент — поменять пресет, а не
префабы и сцены. Сетевые ID слотов выводятся из ключа запуска карты (сервер, клиент, поздний клиент — одна станция).

## Следующий шаг

Не начинать без команды пользователя. При возобновлении: показать пользователю выбор корпусов (plan.md, раздел
«Этап decorations — нужен выбор пользователя»), влить `planning` (документы), затем `acceptance` (два клиента на стенде,
поздний вход, перезагрузка карты, шлем).

## Ждёт пользователя

- Выбор корпусов станции: **A** — корпус = префаб станции (варианты префаба с теми же рядами; каталог корпусов убрать;
  рекомендация прежнего агента) или **B** — сменное оформление поверх корпуса (каталог чистого артворка).
