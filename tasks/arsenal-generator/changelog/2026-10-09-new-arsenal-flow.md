# Новый флоу арсенала: исполнители, раскладка слота, коробка приёма

Дата: 2026-10-09. Задача: arsenal-generator. Тип: refactor + feature.
Статус: принято пользователем в Unity 2026-10-09.

## Результат

- Станцию любой карты собирает генератор при запуске карты; слотов в префабах и сценах нет, авторского режима нет.
  Сборщик станции связывает исполнителей: ряд корпуса (`ArsenalSlotRow`) вешает слоты с шагом «ширина + зазор»,
  сборщик слота (`ArsenalSlotBuilder`) собирает слот по раскладке.
- Пресет — записи «оружие → ряд» и стиль; стиль — только модуль опор и материал подсказки возврата.
- Раскладка слота (`ArsenalSlotLayout`, `Assets/Data/Arsenal/SlotLayouts/`): позы оружия, магазина и карточки,
  размер карточки, опоры, коробка приёма. `Default_Pegboard`/`Default_Shelf` — у префабов слотов; 20 своих
  раскладок у стволов, у остальных — умолчание.
- Коробка приёма `ArsenalAnchorPlaceZone`: приём оружия только когда его точка приёма внутри коробки.
- Стенд раскладки пишет в ассеты раскладок; «Отдельная раскладка» копирует раскладку для одного ствола.
- Удалены: авторский режим и подготовка, шаблоны слотов каталога, адаптер старого представления, превью и
  редакторские сборщики слотов, инсталлятор предложений магазина, зоны/исключения стиля, встроенные раскладки
  `WeaponInfo`, `WeaponHangFitsSlotTests` (проверял «влезает ли»).
- Данные: все карты, Lobby, BotCombatStand и CommonArsenalReview без слотов; ассеты пересохранены; окклюзия
  всех карт перезапечена.
