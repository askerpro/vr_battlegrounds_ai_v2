# Новый флоу арсенала: один формат, без авторских станций

Решение пользователя 2026-10-08: сборщик арсенала не знает деталей и расположения полок и слотов; у арсенала —
дочерние исполнители. Старый (авторский) формат станций удаляется сразу, все карты мигрируют, обратной
совместимости нет (игра не вышла).

## Исполнители и данные

| Кто | Данные | Что делает |
|---|---|---|
| Оружие (`WeaponInfo`) | карточка (имя, цена, характеристики); **раскладка в слоте по виду слота** — позы оружия, магазина, карточки, размер карточки, опоры | — |
| Префаб слота (`ArsenalSlotController`) | ширина слота, якоря оружия и магазина | — |
| Сборщик слота (`ArsenalSlotBuilder`) | префаб слота + оружие | один настроенный слот: ID ролей, позы из раскладки оружия, карточка, опоры, предложение магазина |
| Ряд корпуса (`ArsenalSlotRow`) | ключ ряда, вид слота (зона), префаб слота, точка и поворот слотов, зазор, выравнивание | вешает слоты своими детьми; двигается вместе с корпусом |
| Пресет (`ArsenalPreset`) | порядок: записи «оружие → ключ ряда» | — |
| Стиль арсенала (`ArsenalPresentationStyle`) | только внешний вид: модуль опор, материал подсказки возврата | — |
| Сборщик станции (`ArsenalStationComposer`) | — | связывает: пресет → сборщик слота → ряд; сетевые ID и готовность |
| Корпус станции (префаб) | корпус, ряды, контроллер, склад, сеть; **слотов нет** | — |

Расстояние между слотами — в ряду (зазор) и в слоте (ширина). Позиция ряда — сам ряд в префабе корпуса,
настраивается в Prefab Mode.

## Что удаляется

- Режим станции `ArsenalCompositionMode` (Authored/Generated), `_authoredBinding`; авторская ветка
  `MapBootstrap` (`Prepare` пресета), авторский отпечаток и `AuthoredFallback`/`ModeMismatch` в `MapRoot` и адаптере.
- `ArsenalStationPresetBinding.Prepare` и поиск слотов в иерархии; `ArsenalWallController._allSlots`
  и авторская ветка массива слотов — слоты стены всегда устанавливает сборщик.
- Позы по зоне и исключения в стиле (`ArsenalPresentationStyle._zones/_exceptions`), разрешение поз по стилю,
  `ArsenalLegacyPresentationAdapter`, `Zone` в записи пресета.
- Шаблоны слотов в каталоге (`ArsenalFunctionalSlotTemplate`) и их компиляция из эталонной станции.
- Авторские слоты в префабах `CommonOpenArsenalStation`, `LobbyDemoArsenalStation` и в сценах.
- Редакторские инструменты авторских станций: сборка демо-станции из пресета (`ArsenalPresetAssetBuilder`),
  установщик предложений магазина в префаб, миграции авторских станций — в той части, что пишет слоты.

## Миграция данных (одна команда, под арендой)

1. Раскладка оружия: для каждого оружия пресетов и каждого вида слота — позы из текущего стиля
   (зона + исключение оружия) → `WeaponInfo`.
2. Ряды корпусов: на ряды авторских слотов `CommonOpenArsenalStation` и `LobbyDemoArsenalStation` —
   `ArsenalSlotRow` по авторским слотам (центр, высота, глубина, поворот, зазор), префаб слота вида.
3. Пресеты: `Zone` записи → ключ ряда.
4. Корпуса: авторские слоты удаляются из префабов; станции сцен — без переопределений слотов.
5. Каталог: пересохранить без шаблонов; `MapRuntimeCatalog._arsenalComposition` — каталог.
6. Проверка: `MapGameplayHierarchy.ValidateAll()`, Bake Occlusion (all maps), Android gate, проба
   «сгенерированная = авторская» до удаления (раскладка 0 мм), EditMode.
