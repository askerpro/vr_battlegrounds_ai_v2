# Арсенал: подсветка слотов вместо realtime-ламп

2026-10-22. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/arsenal-slot-lighting` (схема «задача = агент»).

## Цель

Акцент арсенала — сам слот с оружием: на каждый слот запечённый прожектор на невидимом кронштейне (~30 см сверху-спереди) и проба света в центре слота; за стволом светящаяся подложка (материал), её цвет показывает состояние слота (доступно/недоступно/взято) вместо realtime-лампы слота. Плафона над арсеналом нет.

## Этапы

Этапы и области записи — в [plan.json](plan.json). Заготовленный этап `work` пишет только в `tasks/arsenal-slot-lighting/**`: перед `begin` объявите нужные пути (`writes`) и перерегистрируйте план (`register`).

## Решения пользователя 2026-10-23

Слоты станции создаёт код при загрузке карты (`ArsenalSlotBuilder` → `Instantiate`), поэтому запечённый свет в префабе
слота невозможен. Принята схема «свет в сцене по позам»:
- инструмент `ArsenalSlotLighting` (меню `Tools/VR Battlegrounds/Arsenal/Подсветка слотов (свет и пробы в сцене)`)
  считает позы слотов кодом запуска карты (`MapArsenalStationDescriber` + `PlanComposition`) в открытой позе
  оборудования и ставит в `Environment/ArsenalSlotLighting` на каждый слот запечённый прожектор на кронштейне
  сверху-спереди и пробы света в центре слота и перед ним; ночной пресет Lobby этот контейнер не трогает;
- оружие и доска — объекты рантайма: прожектор освещает их через пробу (без пятна); видимое пятно и состояние —
  светящаяся подложка `ArsenalSlotGlow` (Unlit аддитивный квад с мягким пятном) вместо realtime-лампы `LEDs`;
- цвета состояний — как у прежней лампы: доступно — тёплый (1; 0,85; 0,6), недоступно — подложка гаснет,
  слот пуст после взятия — зелёный;
- сейчас только Lobby; карты (ServiceYard, ReferenceMap04, TestMap1/2, BotCombatStand) — после приёмки.
