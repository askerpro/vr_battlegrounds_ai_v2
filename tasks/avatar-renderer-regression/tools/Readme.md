# Исторические инструменты расследования

Эти файлы сохранены как материалы расследования. Они не входят в игровую сборку и не запускаются автоматически. Актуальные регрессии находятся в Assets/Tests/EditMode/Prefabs/AvatarRendererOwnershipTests.cs.

- observe-runtime-renderers.cs — временные диагностические обработчики редактора; захват до Start в проведённом сценарии не подтвердился.
- headset-lease-keepalive.py — продление только собственной аренды при явно разрешённой пользователем ручной проверке. Токен берётся из окружения, завершение аренды останавливает helper. Для финального автоматического прогона не используется.
- validate-cyborg.cs — проверка отклонённого варианта20/EditorOnly на НЕАКТИВНОМ экземпляре. Не является проверкой принятого варианта15 или runtime.
- request-runtime-cyborg.cs — историческая попытка выбора через TeamRegistry. Cyborg в реестре отсутствует, попытка не выбрала его.
- run-existing-regressions.cs — резервная прямая проверка assertions, не запускалась.
- mcp_call.py — диагностический вызов через worktree-прокси. Для итоговых проверок применён штатный native MCP.
- red-tests.json, read-console.json — параметры первоначальных диагностических вызовов.

Любые операции Unity выполняются только через свою RUNNING аренду с guard. Не использовать эти файлы для обхода брокера или изменения чужого Play Mode.
