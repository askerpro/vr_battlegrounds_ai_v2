## Проба `BotStandMatchProbe` (код стенда, только чтение)

Сервер (main-процесс), матч Elimination на штатной карте с ботами (PlayLaunch, BotCount=N, AutoGoLive):
- **Поток матча:** смены фаз/раундов (время, номер), закупки ботов (что, цена, баланс до/после — сходится ли с
  экономикой), выстрелы и попадания по ботам, смерти → призрак → новое тело, конец матча/серии, счёт; события
  с меткой времени — таймлайн.
- **Стоимость сервера:** время кадра (p50/p95/max) по окнам фаз; GC Alloc/кадр и число сборок; маркеры
  ProfilerRecorder верхнего уровня ботов, если доступны без правки кода ботов; число ботов N.
- **Ошибки:** консоль сервера (Error/Exception), ошибки Relay.
- **Сеть (S-топология):** байт/с на бота у клиента-наблюдателя и исход сервера (как в net-round1:
  `NetworkDiagnostics`), сравнить с удалённым человеком-клиентом, если есть.
Наблюдатель на клиентах — переиспользовать `BotStandNetObserver` (только чтение), если применим к матчу; иначе только
клиентская консоль + байты.
