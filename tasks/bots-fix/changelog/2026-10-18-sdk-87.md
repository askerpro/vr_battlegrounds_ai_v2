# SDK87: локальная производная доступность GrabProxy

Дата: 2026-10-18. Номер87 зарезервирован через coordination patch-reserve,
ключ `derived-grab-proxy-local-state`, owner/task `bots`/`bots-fix`.

Unity790 показал клиентские отправки IsGrabbable из UpdateGrabProxyState при
Anchor.Start и UxrMagazinePocket.ForceStoreItem → PlayerLoadoutManager.OnStartClient.
Spectator пересчитывал проекцию чужого SyncList, затем сервер получил три сообщения
с отсутствующим runtime UID. Это другая причина, чем12 незарегистрированных scene Pin.
Подробные факты и пределы сопоставления: ignored reports/spectator-functional-20261018/analysis790.md.

Решение: один внутренний SDK setter с явными syncOptions. Публичный IsGrabbable
сохраняет Default=Network|Replay. Только UpdateGrabProxyState выбирает Replay:
доступность вычисляется по CurrentPlacedObject/ProxyGrabbableQuery на каждой машине.
EndSyncProperty получает явное имя IsGrabbable, чтобы вынос в метод не изменил
CallerMemberName. Второго владельца SDK-состояния и игрового authority внутри SDK нет.
Сериализованный _isGrabbable и формат snapshot остаются прежними.

Проверка впереди: компиляция, независимые ревью manipulation/network, runtime pocket/proxy
empty/full, Start, placement/removal, latejoin/snapshot/replay. До пользовательской
проверки качества новые/переписанные tests не создаются; accepted commit не выполняется.
