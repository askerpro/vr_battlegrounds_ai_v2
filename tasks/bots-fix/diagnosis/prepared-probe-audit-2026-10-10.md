## Текущие критерии authoring A

- `BotCombatSetup.Build()` → `BotClipComposition.Build(folder)` → `BuildCalibration(folder)` только после composition passed. Root сначала получает final SDK71/canonical prefab permission и joint compile.
- Native controllers: Pistol/Rifle по Idle/Move/Back/Left/Right/Shoot (6 states), Unarmed Idle/Move (2); motion-rate float и speedParameter активен только moving states (`BotCombatSetup.cs:113-120`). Layer IK Pass выключен. Ноль enabled SDK controller/IK/tracking/input/grabber writers, один enabled visible human Animator.
- Native bindings: для каждой из двух моделей Pistol4+Rifle4+UnarmedMove1 = 9, всего18; все finite nativeMetersPerSecond>.01 (`BotClipComposition.cs:311-325`). Не принимать 16 или importedAverageSpeed как эквивалент. В runtime `TrySetMotionSpeed` допускает только world authority и использует текущие source/controller/state (`BotClipBody.cs:106-121`).
- Сохранённые MEF/Cyborg generated prefab: BotClipBody NetworkBehaviour (`BotClipBody.cs:19`), одна root NetworkIdentity с отдельным assetId, enabled transport только root и ServerToClient (`BotClipComposition.cs:386-398`), saved rest/bounds/finger mapping исходного geometry. Название модели/количество компонентов alone не достаточны.
- Weapon definitions через `WeaponAutomationCapability.ValidateDefinition`, held capability через ValidateHeld проверять на **reviewed canonical** WeaponInfo references, не EquipmentProbe. Existing fixture сейчас не готова без сверки с joint candidate.
