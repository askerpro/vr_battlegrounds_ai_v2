# Проверка рефакторинга ботов — 2026-10-07

Исторические результаты проверки. Текущий статус: [Readme.md](Readme.md).

Область текущей проверки: MEF и Cyborg. Heavy исключён по поручению пользователя;
его префабы и настройки не изменялись. Рабочая ветка `bots-fix`, база `c0a53921`.
Это инженерная проверка в изолированном Unity worker, не пользовательская приёмка.

## Владельцы и исправления

- `BotRuntimeController` задаёт порядок кадра и допуска; Blaze выдаёт цель и намерение,
  `BotGunner` выполняет одно актуальное намерение после Manipulation с проверкой автора.
- Capability — общий read-only запрос для Shopper/Gunner. M/C принадлежат SDK/оружейной системе;
  единственный вход подготовки — `RequestAutomationPreparation`. Отдельного BeginAutomationSession нет.
- Binding и решатель снимают реальные SDK snap transforms при смене оружия. `BotBody`
  применяет целевые кисти один раз; поддержка захватывается штатным SDK после основного хвата.
- Патч SDK 58 сохраняет входную world rotation кисти до изменения clavicle.
  Второго писателя после IK в BotBody нет.
- После Manipulation Gunner выбирает UXR-позу пальцев по фактическому held object/grab point.
  Если совместимой оружейной позы нет, используется настроенный grab event аватара и его blend.
  SDK применяет кости и переходы; команду позы выдаёт только автор тела.
- Стенд отвергает отсутствующий AvatarIndex вместо скрытой подмены первым скином.
  Cyborg проверен через точный prefab и существующий `AvatarManager.ReplaceBody`,
  без изменения реестров или prefab assets. Actual SourcePrefab проверен перед измерением.

## Воспроизведение и проверка

позиция сохранена с погрешностью <0.002 мм. Transform/cache после probe восстановлены.

sentinel -1 из GetOverrideGrabPoseBlendValue не является ожидаемым blend дискретной позы.
