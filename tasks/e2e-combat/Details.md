# e2e-combat — подробности

## Разведка (2026-10-20, консультации weapon-system и gameplay, только чтение)

- Курок читает `UxrFirearmWeapon.UxrManager_AvatarsUpdated` у локального аватара с руки, держащей точку хвата спуска
  (у всех стволов точка 0); нужен фронт нажатия после хвата (`MustRelease`). Стрельба только в Combat
  (`MapReferee` → `WeaponSystemEnabled = mode.WeaponsEnabled`). Ствол со стены досылается сам (`TryInitializeReadiness`)
  в первые ≤ 0,5 с Combat — подтверждено прогоном (`IsReadyToFire` без передёргивания).
- Выстрел — фиксация учёта UXR (`CommitShotSynced`), сервер повторяет из позы автора, урон применяет сервер
  (`UxrActor.ReceiveImpact` → `Life`), правила — `PlayerController.OnDamageReceiving`. Маска пули — Default|Ground|Hitbox.
- Фазы Elimination: Equipment → Countdown по готовности всех или по пределу 45 с (AutoReady, `Readiness.LimitExpired`),
  Countdown 3 с при всех живых в своих зонах, Combat до победы или 90 с, Resolution 3 с, Scoreboard 5 с.
  Готовность — снять жетон (`DogTagController`) со своей стены. Деньги за убийство — `KillAward` оружия в руке
  убийцы (`MatchEconomy.TransactionServer`, `Reason=Kill`), раунд — 3250 / 1900.
- WallPass в Combat: голова или тело сквозь геометрию — урон без убийцы; ходьба в бою только по свободному пути.
