# Mirror patch 8 — NetworkDiscoveryBase: без автостарта рекламы в headless

2026-10-20, задача `e2e-discovery-autostart`. Номер получен через `patch-reserve` (Mirror, 8, ключ
`discovery-no-headless-autostart`). Маркер в коде: `VR Battlegrounds patch 8`.
Файл: `Assets/ThirdParty/Mirror/Components/Discovery/NetworkDiscoveryBase.cs`, метод `Start()`.

## Что

Удалён апстримный вызов `AdvertiseServer()` из `Start()` при `Utils.IsHeadless()`. Остальное в `Start()`
(`ServerId`, подстановка `Transport.active`) без изменений.

## Зачем

Рекламой Discovery в проекте владеет `GameNetworkDiscovery`: для Server/Host он вызывает `AdvertiseServer()` по
`GameNetworkManager.ServerPublished`, после применения портов шва `PlayerBeforeNetworkStart` и готовности карты (S1).
Автостарт Mirror был вторым писателем: в headless он биндил порт сцены 47777 в `Start()` до применения пары
e2e-плеера. При занятом 47777 (открытый Editor пользователя) сервер писал `SocketException` из
`AdvertiseServer()`, и heavy `--profile windows` падал по логам (код 1); при свободном 47777 изолированный прогон
кратко рекламировал себя на общем порту. Для выделенного сервера автостарт объявлял сервер клиентам до готовности
карты — против S1; затем `ServerPublished` всё равно перезапускал рекламу.

## Поведение

- Headless Server/Host начинает отвечать на discovery только после `ServerPublished`, на применённом порту.
- Оконные процессы (клиенты, хост в шлеме, редактор) не затронуты: у них автостарта и не было.
- Код, вызывающий `AdvertiseServer()` явно, не меняется.

## При обновлении Mirror

Снова убрать ветку `if (Utils.IsHeadless()) AdvertiseServer();` из `NetworkDiscoveryBase.Start()`.
