## Цель

Полноценная сквозная e2e-регрессия геймплея на окружении, близком к продакшну: настоящие сетевые клиенты со
скриптовым вводом и серверный оракул проходят серию — закупка, бой, раунды, переключение и следующая карта, пауза,
стоп, возврат в лобби. Одна команда с профилями:

- **HeavyEditor** — сервер + клиенты в MPPM через аренду worker (быстро, без сборки);
- **HeavyWindows** — собранные Windows-сервер (headless) и Windows-клиенты со скриптовым вводом;
- **HeavyQuest** — APK на шлеме + Windows-сервер, тот же набор сценариев.

Агент в конце работы прогоняет нужный профиль одной командой, получает один вердикт «можно вливать / нельзя» и
уверенно вливает: новые фичи не ломают геймплейную логику.

## Принципы (решения пользователя 2026-10-19/20)

- **Клиенты первыми.** Регрессия — на настоящих сетевых клиентах: сервер видит обычного игрока, бот-путей нет.
  Боты — следом, тем же сценарием, для массовости.
- **Ввод, а не поведение.** Источник ввода (человек, сценарий, Blaze) → кадр устройства (голова, контроллеры,
  кнопки) → аватар. Сценарий не вызывает действий SDK и не меняет игровое состояние напрямую.
- **Маленькие итерации.** Проверенная итерация сразу вливается в origin/dev; тесты — после проверки пользователем.
- **Серией управляет скриптовый клиент-админ** (как в проде: игрок с планшетом).
- **Оракул только читает** реплицированное и серверное состояние.
