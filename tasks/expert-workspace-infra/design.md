# Рабочие места экспертов и awake: проект v2

Дата: 2026-10-11. Статус: v2 согласован пользователем и реализован как candidate; пилот — эксперт `launch-infra` (`experts/launch-infra/`), задача `vr-test-stand` — одна из его задач.
v2 заменяет проект v1 (каталог JSON-карточек, поиск, курсоры, SQLite-адаптер) из коммита
`6c5a54c1`: пользователю нужен только `awake`, всё остальное агент делает штатными средствами.

## Цель

Эксперт — главная сессия с изолированной зоной ответственности и своим рабочим местом. Он
оркестратор: решения, контракты, ТЗ субагентам, проверка их результата. Стартовый контекст не
устаревает: статична только роль/карта, состояние вычисляется из живых источников при запуске.

## Рабочее место `experts/<id>/`

Пишет только сам эксперт.

| Файл | Содержание | Как не устаревает |
|---|---|---|
| `expert.json` | id, owner, task-id, `reviewed_sha`/`reviewed_at`, доп. `watch_paths` | — |
| `AGENT.md` (англ., ≤ 4–5 КБ) | назначение, владеет/не владеет, инварианты, архитектурная карта, где подробности, правила зоны | awake сообщает о коммитах в путях эксперта после `reviewed_sha` |
| `experts/COMMON.md` (общий, англ.) | правила всех экспертов: оркестрация, ТЗ, проверка, ведение, жизненный цикл задач, память | один источник; awake выдаёт его каждому эксперту в блоке `role` |
| `backlog.md` | живой backlog и планы | ведёт эксперт |
| `journal/YYYY-MM-DD-*.md` | решения, итоги проверок, блокировки; первый заголовок — суть | в пакете только заголовки 10 последних |

Основная папка задачи, контракты и хаб остаются источниками фактов; рабочее место хранит выводы
и навигацию, не копии.

## awake

```text
python -B -X utf8 Tools/experts/awake.py experts/<id> [--no-hub] [--max-bytes N]
```

Пакет (Markdown, по умолчанию не больше 24 576 байт UTF-8 (≈6–7 тыс. токенов)):

| Блок | Источник | Обязателен |
|---|---|---|
| Роль и рабочее место, режим координации | AGENT.md, `.agent-state/coordination/config.json` | да |
| Мои задачи и этапы: состояние, SHA, evidence доступно/НЕДОСТУПНО | `coordination.py status` (read-only) | да |
| Входы для ТЗ: writes, контракты с ревизией, after незавершённых этапов | status | урезаемый |
| Мои контракты: ревизия, состояние, implementation, ACK | status | урезаемый |
| Используемые чужие контракты | needs моих этапов, наши ACK | урезаемый |
| Чего жду / кто зависит от меня (без merged) | after/needs всех задач | урезаемый |
| Inbox: счётчики, id/kind/отправитель адресных | `coordination.py inbox` (без тел, без ACK) | да |
| Репозиторий: ветка, ahead/behind origin/dev, незакоммиченные | git, `--no-optional-locks` | да |
| Свежесть AGENT.md | `git log reviewed_sha..origin/dev -- writes+watch_paths` | урезаемый |
| Backlog, журнал | файлы рабочего места | урезаемые |

Бюджет: при превышении урезается крупнейший необязательный блок построчно, с числом скрытых строк
и ссылкой на полный источник. Если не помещается обязательная часть — ошибка
`mandatory_context_over_budget` (код 2), пакет не выдаётся частично.

Отказы: хаб недоступен → явная пометка, задачи/контракты не выдумываются, статика сохраняется;
inbox доступен только из worktree владельца → пометка. Секреты: печатаются только выбранные
поля; токены stage/merge, session_id, тела событий и spec контрактов не выводятся.

Только чтение: нет записи файлов, кэша, bytecode, fetch, ACK, аренд и допуска. Задачу выбирает
пользователь; пакет её не начинает.

## Подключение

Профиль эксперта (`.claude/agents/<id>-expert.md`, `.codex/agents/<id>-expert.toml`) — минимальный адаптер.
Он нужен: без определения агента нет `--agent` и `agent_type`, значит, хук не сработает; frontmatter
задаёт description (по нему делегируют другие сессии), model, skills, memory; тело для `--agent`
заменяет системный промпт. Тело — три строки: кто ты, контекст приходит пакетом awake, запасная команда
awake. Правила поведения, зона, инварианты и правило памяти живут только в `experts/<id>/AGENT.md`.
Профиль Codex (без хука) — команда awake при старте. Шаблоны — `templates/`.

Хук: `.claude/settings.json` SessionStart (startup/resume/clear/compact) вызывает `awake.py --hook <блок>`
отдельной командой на каждый блок. Он читает `agent_type` из JSON хука; для `<id>-expert` с
`experts/<id>/expert.json` кладёт свой блок полного пакета в `additionalContext` (потолок Claude Code —
10 000 символов на вывод одной команды; блок ≤ 9 500):

| Блок | Разделы |
|---|---|
| `role` | роль и рабочее место (AGENT.md) |
| `tasks` | мои задачи и этапы, входы для ТЗ |
| `contracts` | мои и чужие контракты, чего жду, кто зависит, чужие этапы в моих путях |
| `status` | inbox, репозиторий, свежесть AGENT.md |
| `backlog` | backlog, журнал, «дальше» |

Блоки заданы фиксированными заголовками разделов (`HOOK_BLOCKS`), подписаны «блок `x` (n/5)»;
команды идут параллельно, порядок в контексте произвольный. Агенту не нужно вызывать awake вручную.
Чужие сессии — без вывода; ошибка сборки — короткая инструкция запустить awake вручную; код выхода 0.
Пакет возвращается и после сжатия контекста. `--hook` без блока — одна сжатая часть.
Codex: передаёт ли его SessionStart имя профиля, не проверено — профиль Codex содержит команду awake.

Профиль manipulation меняет владелец этапа haptics-system/manipulation-kb (файл в его writes); текст —
`handoff/manipulation-expert.md`, запрос — событие хаба 3272.

## Размещение и выпуск

Инструмент — `Tools/experts/awake.py` (продуктовый, читает `experts/` этого репозитория; не лаунчер
agent-infra, поэтому не в `Tools/agents/`). Рабочие места — `experts/<id>/`, профили — `.claude/agents/`,
`.codex/agents/`, хук — `.claude/settings.json`.

## Проверка

- `Tools/experts/tests/test_awake.py`: проекции хаба на фикстуре другого направления (аудио-ассеты),
  отсутствие секретов/тел, недоступный хаб, `--no-hub`, свежесть по git, бюджет и урезание,
  отказ при переполнении обязательной части, неверный manifest, неизменность файлов и отсутствие
  `__pycache__`, отсутствие предметных имён в коде, блоки хука и сжатый режим.
- Пилот на живом хабе и чистая сессия-субагент по упражнениям `tasks/vr-test-stand/pilot-handoff/Readme.md`.
  Unity не запускается; исторические игровые результаты не перепроверяются.
