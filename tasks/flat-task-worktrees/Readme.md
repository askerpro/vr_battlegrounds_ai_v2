# Единый плоский формат агентских worktree

2026-10-18. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/flat-task-worktrees` (схема «задача = агент»).

## Цель

Создавать и хранить агентские worktree в F:/CodexWorktrees/<task-id> без вложенной папки проекта.

## Этапы

Этап и области записи — в [plan.json](plan.json). Этап `work`: объявить единый формат в правилах и
сохранить поиск истории сессий после переноса существующих worktree. Source-генератор `task-new`,
перенос каталогов и регистрации хаба обслуживает основной агент.

## Изменения

- Правила: корень `F:/CodexWorktrees/<task-id>`, файлы проекта прямо в нём, ветка `task/<task-id>`.
- `session_handoff.py` ищет текущий плоский cwd и прежний `<flat>/Vr_Battlegrounds_ai`.
  Родительский cwd никогда не учитывается, в том числе когда task-id равен `Vr_Battlegrounds_ai`;
  общий `F:/CodexWorktrees` не связывает сессии разных задач. Если helper явно вызван для прежнего
  вложенного корня, его собственный cwd сохраняется, но поиск плоского родителя больше не выполняется.

## Проверка и приёмка

2026-10-18 пользователь принял поведение поиска: собственный плоский cwd и прежний вложенный child
учитываются, общий корень и соседние задачи исключаются. После приёмки добавлены интеграционные
регрессии `Tools/experts/tests/test_session_handoff.py`: выбор временных JSONL-сессий, допустимый
task-id `Vr_Battlegrounds_ai` и поздний переход сессии в прежний child через `turn_context`.
Продуктовый код при добавлении регрессий не менялся; реальная история сессий в тестах не читается.

Фактическая техническая проверка 2026-10-18:

- `session_handoff.py` компилируется встроенным `compile`, без записи bytecode.
- Первичная диагностика парного поиска плоского/прежнего корня выявила неоднозначность parent-fallback
  при допустимом task-id `Vr_Battlegrounds_ai`; после ревью эвристика родителя полностью удалена.
- Повторная компиляция и диагностический вывод для обычного плоского корня и task-id
  `Vr_Battlegrounds_ai`: parent и соседний cwd не совпадают, собственный cwd и вложенный
  `Vr_Battlegrounds_ai` совпадают. Needles содержат только собственный путь и этот child.
  При явном legacy nested target его parent также не совпадает; собственный cwd сохраняется.
- Неизменённые проверки `python -B -X utf8 -m unittest discover -s Tools/experts/tests -v`:
  32 теста, OK, один пропуск (ОС не разрешила symlink); 16.847 с. Это проверки awake/SessionStart,
  а не отдельная автоматическая приёмка изменённого поиска истории.
- Приёмка поведения поиска пользователем получена 2026-10-18; выпуск и миграция каталогов
  подтверждаются основным агентом отдельно.
- После приёмки: единый запуск `python -B -X utf8 -m unittest discover -s Tools/experts/tests -v`
  выполнил 35 тестов (прежние 32 и три новые интеграционные регрессии): OK, один прежний пропуск
  из-за недоступного symlink, 18.772 с. Новые регрессии прошли все три.
