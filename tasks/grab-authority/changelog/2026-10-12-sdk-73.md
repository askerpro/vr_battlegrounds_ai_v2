# SDK-патч 73: сопротивление удерживаемого предмета — только у локального аватара

2026-10-12. Этап `grab-authority/held-motion`. Номер зарезервирован штатным `patch-reserve`
для manipulation. Решение эксперта manipulation; ACK bots 4371, network 4375.

## Что и почему

Сопротивление удерживаемого предмета (`TranslationResistance`/`RotationResistance`,
сглаживание `UxrInterpolator.SmoothDamp*` от позы прошлого кадра) — это ощущение инерции
для игрока за этим шлемом. У руки бота (`UxrAvatarMode.UpdateExternally` на сервере) и у
руки чужого игрока на машине наблюдателя оно даёт отставание предмета от кисти. Теперь
сглаживание применяется, только если предмет держит локальный аватар; иначе предмет
ставится в целевую позу жёстко — как при сопротивлении 0. Значения в префабах не менялись.

## Где

Один файл: `Assets/ThirdParty/UltimateXR/Runtime/Scripts/Manipulation/UxrGrabManager.Manipulation.cs`,
метка `VR Battlegrounds patch 73`.

- `FinalizeManipulation` — к условию `Features.HasFlag(ObjectResistance)` добавлен гейт
  `AllowsHeldResistance(grabbableObject, manipulationInfo)`.
- `SetPositionAndRotationUsingConstraintsInternal` (публичный `Set*UsingConstraints` с
  `useResistance`) — тот же гейт; манипуляция берётся из `_currentManipulations`.
  Незахваченный предмет — прежнее поведение.
- Новые `AllowsHeldResistance` (instance: собственные хваты + хваты look-at детей
  из `DirectChildrenLookAts`, если `DirectLookAtChildGrabbedCount > 0`) и
  `AreAvatarHoldersLocal` (static, один проход по `List<RuntimeGrabInfo>`). Без LINQ и
  без аллокаций. Прецедент — patch 16 (`IsLocalAffordanceGrabber`).

Не менялись: реакция на `AvatarMoved`, порядок кадра, `LocalPositionBeforeUpdate`/
`LocalRotationBeforeUpdate`, ограничения, патчи 12, 16, 18, 25–28, 67, 71.

## Правило держателей

- Держатели предмета — его собственные хваты и хваты его look-at детей. Родитель look-at,
  которого держат только дети (`manipulationInfo == null`), решается по хватам детей.
- Сопротивление отключается, если хотя бы один держатель — аватар в режиме, отличном от
  `Local`. Значит, при смешанных держателях (передача предмета между локальным и
  удалённым аватаром, двуручный хват с ботом) сопротивления нет: сглаживание
  предмета, который одновременно ведёт удалённая рука, только добавило бы отставание от неё.
  На кадры передачи локальный игрок может ощутить отсутствие инерции.
- Хват без аватара (`Grabber.Avatar == null`) решение не меняет: сценарии SDK без
  аватара ведут себя как прежде (с сопротивлением).

## Риски

- `DirectLookAtChildGrabbedCount` обновляется в начале кадра манипуляции. При вызове
  `Set*UsingConstraints` вне этого цикла счётчик может быть устаревшим — тогда хваты
  детей проверяются по прошлому кадру. В проекте вызовов `Set*UsingConstraints` нет.
- Файл раньше был чистым ASCII (без BOM); после патча — UTF-8 без BOM, CRLF сохранён.
