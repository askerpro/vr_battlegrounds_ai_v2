# UltimateXR patch 85 — перенос ссылок после смены prefab parent

Резерв: `coordination.py patch-reserve`, sdk `ultimatexr`, key
`cyborg-prefab-reference-remap`, номер85. Пользователь продолжает согласованную
реструктуризацию базы кистей; самостоятельной механики SDK эта правка не добавляет.

Потенциальные outputs — четыре sample prefab в
`Assets/ThirdParty/UltimateXR/Samples/FullScene/Prefabs/ShootingRange/Weapons/`:
`Shotgun.prefab`, `Machinegun.prefab`, `Gun.prefab`, `Grenade.prefab`.
Они хранят editor-ссылки на root `PlayerControllersCyborgAvatar` с прежним local fileID.
После native смены родителя GUID сохраняется, local ID корня меняется.

Writer `CyborgPrefabReferenceRemap` снимает существующие поля/override-наборы до
смены предков и переназначает ссылку на тот же prefab/object по смысловому ключу.
Только Unity SerializedObject/PrefabUtility; YAML не переписывается.
Позы, GUID записей хвата, механика, боезапас, звуки и сеть не пересчитываются.
