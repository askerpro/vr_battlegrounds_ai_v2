# Опорные точки контакта фаланг — v1

2026-10-15. Решение пользователя: ручная разметка и площадь не нужны; выбрать один полигон
на ладонной коже около середины каждой фаланги и обеспечить касание ±2мм. Одна кисть — источник;
вторую зеркалим. Наработки площади сохранены в drafts/contact-area-20261015.

Уточнение solver: distal-palm-contact-ik-v2.md задаёт явные цели кончиков/ладони и ползунок
приоритета; его целевая функция заменяет описанную ниже одинаковую полосу для всех IK targets.
Материальные точки и измерения v1 остаются основой, но прежний solver не считать готовым v2.

Выбор делается один раз в эталонной позе без предмета. Начальный профиль MEF_cyborg_hands,
SDK Default Fixed. Реальные proximal/intermediate/distal сегменты рига, distal tip из SDK.
Нет валидной ладонной грани — missing, без скрытого fallback. Материальная точка хранит mesh binding,
сторону, source renderer/submesh/original triangle и barycentric; после BakeMesh остаётся тем же
участком кожи и не перевыбирается по близости к оружию.

Критерий: расстояние КАЖДОЙ точки до поверхности предмета не больше2мм. Выводятся расстояние и
within-band по каждой точке, measured/expected/missing. Площади и legacy SDK-band не участвуют.
Empty/stale/duplicate/nonfinite не дают ноль/PASS. Unknown signed остаётся null; unsigned nearest
distance оценивает близость, но не доказывает отсутствие проникновений. Zero-area object triangles
исключаются из query с явным счётчиком; весь объект из zero-area или nonfinite — invalid.

Зеркало — отражение поперечной оси анатомической рамки одноимённых фаланг. Projection≤1мм,
согласованная нормаль/segment и уникальный материал обязательны. Иначе missing/error.
Inferred=true сохраняется в JSON. Человеческая проверка выбранных/зеркальных точек требуется.

IK: явный FixedPointBand mode, штраф только за выход этих точек из2мм band. Нет XYZ/normal или area
attraction-нормы. TargetsReached отделён от Solved; fullskin collision guard, reviewed/reliable/feasible
условия отдельны. UltimateXR остаётся единственным runtime writer. Окно/preview solver не сохраняют
игровые позы/префабы и не меняют кости, веса или масштаб рига.

Поддерживающая рука пистолета исключена из текущего этапа и оценки по решению пользователя.
Она преимущественно касается ведущей кисти; её отдельный контактный приёмник реализуется после
пользовательского подтверждения хороших хватов основного метода. Не оценивать её как контакт с рукоятью
и не включать в общий PASS текущего этапа.

Реальные PNG с гранями/точками встраиваются в Markdown. Offline-компиляция и диагностика не заменяют
Unity, gameplay или Quest приёмку. До пользовательской проверки не создавать и не переписывать тесты,
включая временные smoke-проверки и managed probes. Применимые существующие проверки разрешены;
новые тестовые ожидания закрепляются только после приёмки. Accepted commit/merge нет.
