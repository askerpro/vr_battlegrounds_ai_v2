# SDK-патч UltimateXR 66: форма сигнала и параметры воспроизведения в UxrHapticClip

Дата: 2026-10-08. Задача: haptics-system. Этап: clips-interaction. Тип: sdk.
Статус: реализовано, не проверено. Номер выдан `coordination.py patch-reserve` (ключ `haptic-clip-waveform`).

## Результат

Клип вибрации SDK становится единственным типом «точки интеграции» и в компонентах UltimateXR, и в коде игры:

- `Runtime/Scripts/Haptics/UxrHapticWaveform.cs` (новый) — ассет-форма: отрезки «сила 0..1 × мс», длина, `Sample(t)`,
  событие `Changed` (правка в инспекторе).
- `Runtime/Scripts/Haptics/UxrHapticPriority.cs` (новый) — Low / Normal / High / Critical.
- `Runtime/Scripts/Haptics/UxrHapticClip.cs` — поля `_waveform`, `_waveformGain` (1), `_priority` (Normal),
  `_repeatGapMs` (0), `_cooldownSeconds` (0), `_secondaryHandGain` (1) с свойствами, `HasWaveform`; конструктор без
  параметров, чтобы Unity выполнял инициализаторы полей во вложенных экземплярах.

Инвариант: клип без формы ведёт себя как до патча — SDK играет `Clip`/Fallback*. Клип с формой играет игровой
`HapticService` (до этапа `sdk-routing` — только из кода игры; в компонентах SDK форма начнёт играть после перехвата).
State save и сетевая синхронизация SDK клипы не копируют и не синхронизируют — поля на них не влияют. Старые ассеты без
ключей получают значения по умолчанию.

## Как повторить при обновлении SDK

Вернуть два новых файла и шесть полей + свойства + конструктор без параметров в `UxrHapticClip`; метки в коде —
`VR Battlegrounds patch 66`.
