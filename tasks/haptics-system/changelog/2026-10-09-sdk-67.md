# SDK-патч UltimateXR 67: кандидат хвата по руке

Дата: 2026-10-09. Задача: haptics-system. Этап: interaction-feedback. Тип: sdk.
Статус: реализовано, не проверено. Номер выдан `coordination.py patch-reserve` (ключ `grab-candidate-events`).

## Результат

`UxrGrabManager.UpdateAffordances` в первом проходе подсказок хвата уже вычисляет для каждой локальной пустой руки
ближайший предмет, который возьмёт grip (`GetClosestGrabbableObject`, тот же вызов, что при нажатии). Раньше результат
шёл только во включение `Enable On Hand Near` точки хвата. Патч сохраняет его:

- `Runtime/Scripts/Manipulation/UxrGrabManager.cs` — три вызова с меткой `VR Battlegrounds patch 67` в первом проходе
  (`BeginGrabCandidatesFrame`, `SetGrabCandidate`, `EndGrabCandidatesFrame`).
- `Runtime/Scripts/Manipulation/UxrGrabManager.GrabCandidates.cs` (новый partial): запрос
  `TryGetGrabCandidate(grabber, out item, out grabPoint)` и событие `GrabCandidateChanged(grabber, item, grabPoint)` на
  смену кандидата (item = null — кандидата нет).

Инвариант: новых расчётов нет — только сохранение результата прохода; отбор рук прежний (локальные, патч 18). Проход
«рука рядом с предметом в якоре» (патч 26) остаётся выключенным: «можно взять из якоря» берётся из того же кандидата
хвата (предмет в якоре или прокси кармана), поэтому `GrabberNear`/`Activate On Hand Near And Grabbable` остаются
нерабочими, как и до патча.

## Как повторить при обновлении SDK

Вернуть partial-файл и три вызова в первом проходе `UpdateAffordances` (до/внутри/после цикла по `UxrGrabber.EnabledComponents`).
