# Политика heavy: обязателен для геймплея и сети, не для визуальных правок

2026-10-22. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/heavy-policy` (схема «задача = агент»).

## Цель

Heavy-регрессия обязательна для изменений геймплея, сети, runtime-кода, префабов игрока/оружия/сетевых объектов, тестовых карт, ProjectSettings и Packages; для чисто визуальных правок (материалы, шейдеры, текстуры, освещение, пост-обработка, звук, декор Lobby) не требуется.

## Этапы

Этапы и области записи — в [plan.json](plan.json). Заготовленный этап `work` пишет только в `tasks/heavy-policy/**`: перед `begin` объявите нужные пути (`writes`) и перерегистрируйте план (`register`).
