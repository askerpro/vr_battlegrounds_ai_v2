## 1. Концепция и визуальные референсы

Рабочая цель реализации — лесной вариант: оливковый/песочный брезент, широкий
открытый каркас, пустой центр для движения игроков, оружейные станции по краям.
Ящики, генератор, контейнеры и служебная зона — снаружи доступного центра.
Фон стрельбища: грунт, земляной вал, хвойный лес, немного камней;
маскировочная сеть и HESCO не обязательны для первого среза.

  Теги — GameTags/GameTagRules. Общие индексы, SDK-журналы и чужие задачи не редактировать.

Проверено наличие именованных файлов, не прослушивание или качество петли.
Проезд подходящего тяжёлого грузовика и естественная дальняя стрельба — внешние
кандидаты: [truck/APC pass-by](https://freesound.org/people/kyles/sounds/405086/),
[Humvee convoy](https://freesound.org/people/qubodup/sounds/160357/),

В подборе 06.10 для них указывалась CC0; до получения файлов повторно проверить
лицензию и сохранить её. Не использовать CC BY-NC/BBC RemArc для коммерческой игры.
Цены старых платных подборов не считать актуальными: платный вариант сначала
предъявить пользователю с текущей ценой и причиной, почему бесплатный не подходит.

**Стартовые параметры прототипа, затем настроить на слух:**

| Событие | Продолжительность эпизода | Повтор одного типа не чаще | Источник |
|---|---|---|---|
| Вертолёт | 15–30 с | случайно 180–420 с | Движение высоко и снаружи арены |
| Грузовик | 10–25 с | 90–240 с | Движение по дороге вне площадки |
| Далёкая стрельба | 3–10 с | 45–120 с | Неподвижная точка за валом |
| Солдаты | 6–12 с | 45–120 с | Далёкая точка/короткий внешний маршрут |

После эпизода общая пауза 20–40 с; из доступных типов выбирать случайно,
не повторять тот же клип подряд, если есть варианты. Максимум: фон + один эпизод,
два AudioSource. Случайные интервалы не требуют одинакового seed между клиентами:
это косметический локальный фон, не синхронизированное игровое событие.

3D — моно, SpatialBlend=1, приоритет эмбиента 180, мягкие края слышимости.
Готовое стереопанорамирование — только 2D. Громкость подбирать сравнением с
реальными выстрелами, шагами и голосом, а не по названию файла.
Для коротких событий использовать существующий SfxImportSettings.Apply(paths):
моно/Vorbis 0,7, меньше 1 с — Decompress On Load, остальное — Compressed In Memory.
Для длинного стереофона настройки задавать отдельно: Streaming, Vorbis 0,5–0,6,
не пропускать через утилиту, которая принудительно делает моно.

## 7. Риски, которые проверить на прототипе

1. Шатёр/растяжки визуально скрывают физические опоры или нарушают проходы —
   проверить по измеренной площадке и в шлеме.
2. Раскрытая станция цепляет мешки/кромку крыши — проверить оба состояния.
3. Деревья/полотно увеличивают GPU-стоимость — сравнить Quest-замеры и настроить LOD/тени.
4. Фоновая стрельба принимается за действия игроков — настроить дистанцию/громкость,
   при необходимости заменить запись, не менять реальные weapon SFX.
5. Повторное включение/смена карты дублирует расписание — проверить lifecycle;
   после приёмки закрепить автоматической проверкой.

в локальных reports/; они не нужны как обязательное чтение этого плана.
