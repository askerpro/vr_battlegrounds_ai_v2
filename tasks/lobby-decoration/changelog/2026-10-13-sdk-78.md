# SDK-патч 78 (UltimateXR): планарное зеркало — только в кадре и только ближний план

2026-10-13, задача `lobby-decoration` (owner level-design), ключ резерва `mirror-visible-near`.
Решение пользователя: зеркало рисуется только когда оно в кадре; в отражении — ближний план и люди,
остальное не рисуется (бюджет GPU Lobby ≤ 7 мс, «в ущерб картинке»).

Файл: `Assets/ThirdParty/UltimateXR/Runtime/Scripts/Rendering/FX/UxrPlanarReflectionUrp.cs`.

- `IsMirrorInView`: отражение не рендерится, если bounds зеркала вне пирамиды видимости камеры
  (`cullingMatrix`, для XR — общая на оба глаза) или камера за отражающей плоскостью. Текстура хранит
  последний кадр.
- Поле `_maxReflectionDistance` (0 — как в SDK): `layerCullDistances` камеры отражения по всем слоям =
  расстояние камеры до плоскости + `_maxReflectionDistance`, сферически. Дальнее не рисуется, вместо него фон.
- Камера отражения без теней, пост-эффектов, depth/opaque-текстур (`UniversalAdditionalCameraData`).

Причина: разбивка GPU performance (события 5603, 5742) — две внеэкранные поверхности зеркала каждый кадр
3,7 мс при 1500×1500 и 2,46 мс при 768×768: дорог повторный рендер всей сцены, а не разрешение.
Затронуты все зеркала с этим компонентом; без `_maxReflectionDistance` поведение по дальности прежнее,
проверка видимости действует везде.
