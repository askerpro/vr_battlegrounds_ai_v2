Всего 26 экземпляров vendor prefab и одна тонкая процедурная подложка места сборки
2.2×3.3 м. Подложка — собственный матовый URP/Lit материал, без текстуры;
это явно процедурная поверхность, а не источник из MilitaryCamp.
Балки действительно 5.060 м, несмотря на имя `3m`; масштаб всех источников 1.
Сваи кладутся горизонтально; следующие слои лежат на предыдущем без смещения.
Трубы лежат одним слоем на грунте, без неподдержанной пирамиды.
Профиль сборки опирается на верх подложки, +0.004 м.

PNG балок, обоих типов свай, профиля, барьера, pipe15 и cabinet_a/b открыты через view_image.
`SM_pipe_01/02_a` — короткие муфты, не используются.
`SM_ToolRack` — пустая панель, не используется.
`SM_cabinet_a/b` фактически открытые пустые полки, не закрытые шкафы;
по прямому решению root они также полностью исключены из стройплощадки.
Инструментальный узел root признал необязательным для текущего brief.

Каждый prefab сохраняет все исходные LODGroup/уровни/материалы и дочерние mesh transforms.
Нет ForceLOD, коллайдеров, скриптов, Animator, Animation, Light, теней и probe-запросов.
Sanitize действует только на экземплярах. Нет игровых тегов или навигации.
Отсутствующий источник, null material, пустой LOD, неподходящая ориентация длинного
материала, выход из footprint/зоны, пересечение реквизита/шатра и повторный Build
вызывают исключение. При ошибке собранная группа целиком удаляется; исходники не затрагиваются.
Преднамеренные контакты слоёв стопок и подложки места сборки не считаются конфликтом.

Проверки: `offline_compile.ps1` компилирует helper и read-only source resolver
против Unity 6000.4.1f1. `source_evidence.py` проверяет точные prefab paths/GUID/LOD metadata;
артефакт `reports/implementation/construction-zone/source-evidence.json`.
Новых игровых тестов нет. Native Build, сохранение сцены, итоговые world bounds,
реальное отсутствие runtime компонентов, читаемость стопок с уровня глаз, Quest frame budget
и пользовательское принятие проверяет ведущий/root.
