## Решения и предложения

- Верхний ярус (площадки налива, лестницы резервуаров) только декоративный:
  игровой верхний ярус требует отдельной механики подъёма.
- Предложение: на уровне игрока простые формы, сложная геометрия НПЗ — силуэты в фоне.

Не выбрано: объект (нефтебаза, установка НПЗ или смешанный), время суток (ночь с факелом, пустынный полдень, пасмурный северный завод), одна из трёх планировок.

выборочно с сохранением GUID по `Docs/level-design/environment-pack-policy.md`.
