## Решения и предложения

- При физической ходьбе на второй ярус не подняться. Предложение: арена на мезонине
  над зоной сортировки, пол склада с погрузчиками и конвейером — фон внизу.
- Длинные проходы между стеллажами разбивать укрытиями, чтобы они не простреливались насквозь.

Не выбрано: время и режим работы (ночная смена, дневная, авария питания), где стоят игроки, тип склада, режим игры.
