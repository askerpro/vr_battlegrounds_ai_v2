# Прогрев UltimateXR не запускается на сервере без своего игрока

Обновлено: 2026-10-14. Владелец: эксперт `network`. Worktree: `F:/CodexWorktrees/network/Vr_Battlegrounds_ai`,
ветка `claude/network`. Решение пользователя 2026-10-14: «сторож + корень у avatar-ik». Дефект bots 6231
(копии 6233/6235), данные performance 6245, позиция avatar-ik 6296.

## Проблема

`UxrManager.Avatar_Enabled` перезапускает прогрев, когда включается единственный Local-аватар. На сервере без
своего игрока каждое новое тело в момент Instantiate ещё Local, и прогрев перезапускается на каждом спавне; при
нескольких спавнах в одном кадре копии прогрева копируются с удвоением. `HeadlessPrecacheGuard` выключал прогрев
только при batchmode или без графики, поэтому сервер в редакторе и оконный сервер с графикой не были защищены:
матч 8 ботов повесил worker-редактор (40 ГБ, тикет 600).

## Решение

`HeadlessPrecacheGuard`: прогрев не нужен машине без графики и процессу «только сервер»
(`NetworkServer.active && !NetworkClient.active`). Решение при загрузке каждой сцены (роль известна после старта
сети; сервер после старта всегда грузит сцену карты до первого спавна тела). Регистрация выключенных компонентов
UniqueId — побочная работа прогрева — выполняется сторожем в тех же условиях. Хост и клиенты не затронуты.
Корень в SDK (перезапуск прогрева и клонирование недоуничтоженных копий, `UxrManager`) — у avatar-ik отдельным
SDK-патчем, он закроет и клиента позднего входа.
