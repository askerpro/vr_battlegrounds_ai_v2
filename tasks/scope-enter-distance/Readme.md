# Дистанция включения увеличивающего прицела — параметр

2026-10-24. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/scope-enter-distance` (схема «задача = агент»).

## Цель

Расстояние глаза за окуляром, на котором включается камера кратности увеличивающего прицела (сейчас 15 см, выход 20 см, зашито в компоненте), сделать настраиваемым параметром в общих настройках прицелов рядом с допуском ракурса.

## Этапы

Этапы и области записи — в [plan.json](plan.json). Заготовленный этап `work` пишет только в `tasks/scope-enter-distance/**`: перед `begin` объявите нужные пути (`writes`) и перерегистрируйте план (`register`).
