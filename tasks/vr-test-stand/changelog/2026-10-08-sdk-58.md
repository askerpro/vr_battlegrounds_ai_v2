# UXR patch 58 — процессная политика паузы XR

Дата: 2026-10-08. Владелец: vr-test-stand. Резерв coordination: UltimateXR / 58 / play-launch-focus-pause.
Статус реализации и приёмки: Readme.md; SDK/runtime ещё требует проверки Unity.

Файл: Assets/ThirdParty/UltimateXR/Runtime/Scripts/Core/UxrManager.cs, только UNITY_EDITOR.
BindEditorFocusPauseProvider задаёт одного provider checkout-профиля; BeginEditorFocusPauseOverride
даёт эксклюзивный IDisposable-scope запуска. Getter использует scope → provider → legacy EditorPrefs fallback.
Setter отказывает при наличии владельца вместо изменения общих ключей. Legacy импорт — только
явное действие человека; игровые сборки этой политикой не меняются.

Scope не сбрасывается в SubsystemRegistration: его создаёт Editor до входа в Play без reload.
Puppet/Clip стенды используют свой scope только при обычном запуске; managed launch сохраняет
единственного владельца. Инфраструктурные тесты переведены на scope; в Unity ещё не запускались.

Приёмка: Android compile, отсутствие изменения EditorPrefs/профиля, пауза каждого процесса,
возврат к checkout-профилю после Stop/ошибки/reload и работоспособность существующих стендов.
