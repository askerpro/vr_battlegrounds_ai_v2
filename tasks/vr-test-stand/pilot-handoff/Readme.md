# Пилот миграции рабочей зоны эксперта

Обновлено: 2026-10-10. Пилот: `vr-test-stand`. Разработчик универсального workflow использует этот пакет как исходные данные. Формат будущей рабочей зоны он проектирует отдельно: материалы не задают обязательную схему каталога.

## Быстрый вход

1. Этот файл: назначение пилота, границы и задания проверки.
2. [sources.md](sources.md): карта архитектуры и адресный поиск подробностей.
3. [snapshot.json](snapshot.json): датированный снимок этапов, результатов и backlog.

Затем свежие inbox/status хаба и основной [plan.json](../plan.json), когда нужна актуальная координация. Снимок не выдаёт допуск и не заменяет хаб. Пользователь может явно выбрать любую задачу; последнее обновление карточки не определяет выбор автоматически.

## Что уже есть

PlayLaunch запускает роли в MMP и владеет замороженным конфигом; адресные команды выбирают процесс по RunId/ParticipantId/ProcessSessionId. Есть disconnect/reconnect, контроль epoch/avatar, cleanup, сбор логов всех участников и локальные порты Default/Fixed/Auto.

Принятый код: `51c8c047` — интеграция запуска; `9bcef90d` — инструкции; `07002dde` — порты. Три этапа подтверждены хабом как merged. Сетевая автоматизация готова в указанном объёме; XR-ввод и полный игровой цикл покупки/стрельбы/победы не реализованы этим стендом.

## Граница миграции

Сохранить task-id, существующие источники, контракты и evidence. Создать навигацию и компактные представления, не переносить весь журнал Details.md в стартовый контекст. Стенд не становится владельцем broker/proxy, механики оружия, хвата, экономики или раундов.

Не запускать Unity ради проверки workflow. Документы, поиск и synthetic fixtures достаточны для его собственной проверки. Генерация отчёта не означает новую проверку игры.

## Задания чистой сессии

- Восстановить назначение, владельцев сущностей и границы за несколько запросов.
- Найти завершённый этап портов, его commit и реальные проверки, отделить warnings и ограничения.
- Найти, почему negative377 отозван; не принять его aggregate PASS.
- По явному запросу пользователя выбрать XR-input backlog, не начать последний завершённый этап.
- Найти контракт play-launch-control и владельца map-startup-route.
- Объяснить, где доступны полные логи383 и что делать, если их нет в новом checkout.
- Сформировать ограниченный вывод при большом каталоге и недоступном хабе, сохранив инварианты и указатель дальнейшей навигации.

Миграция считается проверенной только после этих упражнений в чистой сессии. Исторические Unity-результаты не являются её acceptance.
