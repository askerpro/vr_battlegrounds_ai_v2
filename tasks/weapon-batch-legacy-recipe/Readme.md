# Оружие: полный рецепт для AR15/FabarmSDASS, патроны в гнёздах, _orig механики и чистка хватов

2026-10-23. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/weapon-batch-legacy-recipe` (схема «задача = агент»).

## Цель

Одним паком: AR15 и FabarmSDASS на полный рецепт Hands без доноров (звуки, механика, подсветка из пака); патрон в гнезде Herrington и FabarmSDASS вложенным экземпляром префаба патрона; убрать кнопки-наследие вкладки «Взаимодействие»; _orig для затворов и помпы; поза магазина TR15; чистка записей MEF_Base_Avatar; вторая точка хвата BrowningHiPower_Magazine.

## Решения пользователя (2026-10-23)

- Всё недоделанное по оружию — одним паком, heavy один раз в конце.
- Не из пака и не баланс у AR15/Fabarm: скорость и дальность снаряда — в `WeaponInfo` и процедуру баланса (один владелец для
  всего арсенала); физика, хват, якорь — общие значения сборщика по категории. Доноры AR15/Fabarm не читаются.
- Звуки: нарезать из пака тем же инструментом, что у KINEMATION (AR15: выстрел `Rifle_Shot`, затвор и магазин — куски
  `Reload.mp3`; Fabarm: выстрел `shot`, помпа из `Zatvor.mp3`, заряжание `Reload_1`) — послушать и решить.
- Ход затвора и спуск AR15 — искать в клипах пака (диагностика на worker), константы — только для того, чего нет.
- BrowningHiPower_Magazine: убрать вторую точку хвата; сборщик убирает дополнительные точки магазина без записей.
- MEF_Base_Avatar вывести полностью: чистка записей в 34 префабах, сборщики/перенос хватов/импорт поз Hands/Grip Extraction
  больше не пишут MEF, цель по умолчанию — семейство Cyborg; префаб MEF остаётся (стенды, сборщик ног).
- Удалить доноры `M16_Magazine`, `Shotgun_real_mag`, `Shotgun_real` (с правкой миграции имён).
- Общие значения сборщика вместо доноров для всех Hands и KINEMATION: константы в коде (`HandsPackBuildDefaults`) с поправкой
  на механику (исследование E: оставшиеся донорские поля одинаковы у всех 20 префабов). Режим огня — из баланса (флаг
  автоматического огня WeaponInfo; ручная перезарядка — рецепт, FABARM явно). Выстрелы всех стволов Hands — нарезка из своего
  набора пака. Удалить все донор-снимки `LegacyBuildDonors` (BrowningHiPower берёт теги/длину/шаблон из рецепта; снятие
  `CaptureDonors`, правка миграции имён и preflight). Снаряд FABARM — как есть (длина 0.34, толчок 50, декаль Default) явно
  в рецепте. Порог затвора 0.855, `Magazine_drop`, громкость помпы 0.3, вспышки — текущие значения константами.
- `_orig` деталей механики — сразу все стволы с затвором/помпой, схема `Slide`/`Pump`
  (`<Пак>_<Предмет>_<Slide|Pump>_orig`, snap `<оружие>/<Slide|Pump>/Orig/<поза>/Left|Right`).

- Архитектура (подтверждено пользователем): паспорт оружия — `WeaponInfo`; режим огня — из баланса, ручной цикл — свойство
  механизма в рецепте, при сборке сверка «паспорт ↔ механизм» (отказ, если ручной механизм, а паспорт просит автомат).
- Затворы без источника в паке (диагностика 1103: рука берёт затвор только у SRM12; AK105 — рука на рукоятке без движения;
  помпа FABARM — жёстко, но ладонь в 86 мм): snap-точка расчётно по геометрии детали + хват Cyborg создаётся инструментом,
  пользователь доводит в редакторе.
- Звук вставки магазина — у каждого ствола свой, кусок клипа перезарядки пака (момент, когда магазин встал в гнездо), в
  `AudioSource` гнезда `MagAnchor` (не в магазине — иначе дважды); нет в клипе — общий `MagazineAnchorSoundDefaults`. Отменяет
  прежнее «все гнёзда одним общим звуком» (`AmmoInsertSoundTests.Гнёзда_магазинов_звучат_общим_звуком` — обновить после приёмки).
- AR15: в клипах пака затвор и спуск неподвижны (диагностика 1103) — ход (0,0,−0.06) и спуск 40° константами «нет в паке».

## Этапы

План и исследования — [Details.md](Details.md), [research/](research/). Этап `work` ([plan.json](plan.json)):
1. Патрон в гнезде Herrington и FabarmSDASS вложенным экземпляром (`ManualLoadingAuthoring`); убрать кнопки-наследие.
2. Скорость и дальность снаряда в `WeaponInfo`/баланс; общие значения сборщика по категории.
3. AR15 и FabarmSDASS на полный рецепт: рецепты, звуки из пака, ход из клипов, общий MechanismMotion, позы Grip/Support
   `_orig`, легаси — только BrowningHiPower, удаление трёх доноров.
4. `_orig` деталей механики (все стволы с затвором/помпой); поза магазина TR15 (поиск кости детали).
5. Вывод MEF_Base_Avatar и чистка; вторая точка BrowningHiPower_Magazine.
6. Звуки взаимодействия (пользователь 2026-10-23): дефолты «взять/положить» по роли анчора (стойка арсенала, спина,
   бедро, карман магазинов) в одном ассете — расширение `MagazineAnchorSoundDefaults`; удары при падении (`ImpactSound`)
   и гильзы (`WeaponEjecta` через `WeaponSystemAuthoring`) — у своих владельцев. Клипы — по меткам пользователя из
   `reports/sound-candidates/` (исследование G), нарезка в моно. Убрать SDK-звук хвата у `AR15_Magazine`.
   Решение пользователя: звуки оружия (выстрел, затвор/помпа, снятие/вставка магазина) — сразу из паков (нарезка
   сборщиком); пользователь выбирает только универсальные: анчоры по ролям, падение оружия/магазина/гильзы и запасной
   звуки гнезда магазина по категории — по одной паре снять/вставить на винтовку (автомат), пистолет, дробовик,
   снайперскую винтовку — только если в паке ствола своей перезарядки нет.
   Решение пользователя: звуковые дефолты не хардкодить в код — ассеты, на которые ссылаются компоненты, с подстановкой в
   момент проигрывания: категории оружия — `WeaponFeedbackDefaults` (Rifle/Shotgun/Pistol/Sniper: гнездо магазина, гильзы,
   «нет патронов»), роли анчоров — `MagazineAnchorSoundDefaults`, падение оружия/магазина — ассет дефолтов ударов.
   Пустое поле объекта = дефолт ассета; свой клип объекта (нарезка пака, `AnchorSoundOverride`) — оверрайд.
   Карманы — из пака KINEMATION (решение пользователя): пистолет (бедро) взять/положить —
   `SFX/General/S_DrawPistolWithHolster.WAV` / `S_HolsterPistolWithHolster.WAV`; винтовка (спина) —
   `SFX/General/S_Equip.WAV` / `S_UnEquip.WAV`; в дефолты ролей `MagazineAnchorSoundDefaults` (моно-нарезка при
   необходимости). Из подборки кандидатов убраны. Стойка оружия (роль World) взять/положить —
   `SFX/General/S_Aim_In.WAV` / `S_Aim_Out.WAV` (решение пользователя).
   Падение гильз по категориям (`WeaponFeedbackDefaults._ejectaImpacts`, решение пользователя): пистолеты —
   `CASING_9mm_Hard_Surface_RR4_mono`, винтовки — `CASING_7-62_mm_Hard_Surface_RR3_mono`, дробовики —
   `CASING_Shotgun_Shell_Hard_Surface_RR1_mono`, снайперские — `CASING_45_Hard_Surface_RR2_mono`; импорт из
   `_SoundLibrary/Universal Sound FX` с `.meta` в `Assets/Audio/SFX/Casings/` (wav — `binary`, не LFS), импорт под Quest
   (моно, Vorbis 0,7, Decompress On Load) — в Unity.
   Снятие магазина — универсальный дефолт всех категорий (`WeaponFeedbackDefaults._magazineTakeOut`):
   `HANDLING_B_FS92_9mm_Remove_Empty_Magazine_mono` (импорт в `Assets/Audio/SFX/Handling/`); нарезки пака ствола
   (именованные для оружия) остаются его оверрайдом. Вставка магазина — нарезки пака ствола, универсал всех категорий
   (`WeaponFeedbackDefaults._magazineInsert`) — `Assets/Audio/SFX/Universal/Magazine_attach.mp3` (решение пользователя).
   AX-50 Auto (`SniperRifleAuto`, задача arsenal-combat-lineup) заменяет ручной AX-50 (`SniperRifle`) — решение пользователя
   2026-10-23: Auto собирается нашим сборщиком (рецепт на базе `SniperRifle`, механизм не ручной, автомат — из баланса);
   ручной убрать из игры (реестр, стенд ботов, каталог композиции), файлы префабов и `WeaponInfo` оставить.
7. Пересборка арсенала, проверка на worker, приёмка пользователем (звуки, стрельба в Play/шлеме), тесты, heavy, ревью, вливание.
