# Материалы оружия M_*: тёмный оружейный металл как у Hands_*

2026-10-23. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/weapon-metal-materials` (схема «задача = агент»).

## Цель

Поправить материалы оружия на M_* (не пак Hands Weapons), чтобы металл выглядел как у стволов на Hands_*: тёмный оружейный металл с бликами и видимыми деталями, без хрома и без ровной серой вуали. Правка только в материалах/импорте текстур.

## Находки (2026-10-23)

- `M_*` в `Assets/Art/Weapons/Kinemation/Materials` — URP Lit, сделанные конвертером
  `Assets/Editor/VR_Battlegrounds/Gameplay/KinemationMaterials.cs` из Shader Graph пака
  (`Shader_TacticalShooterWeapon`: металличность = lerp(x, y, карта), гладкость = lerp(x, y, 1 − шероховатость),
  карты пака импортированы sRGB, затенения нет — Occlusion = 1).
- Конвертер расходился с шейдером пака: гладкость = 1 − lerp(x, y, шероховатость) (у диапазонов с x = 0 —
  гладкость до 1 вместо y) и карты читались без линеаризации (металличность завышена). Средние по карте
  (пак → было): SRM-12 гладкость 0,55 → 0,82, металл 0,12 → 0,27; Herrington 0,51 → 0,75, 0,20 → 0,30;
  AK105 металл 0,28 → 0,43; Mk14 гладкость 0,55 → 0,66; TR15 0,53 → 0,58. Это «хром» под ровным источником.
- Исправление: формула и линейное чтение в конвертере, меню
  `Tools/VR Battlegrounds/Weapons/KINEMATION: перепаковать металличность и гладкость` пересчитывает PNG
  (`*_MetallicSmoothness.png`, GUID те же). Материалы и остальные карты не меняются.
- Тот же дефект скопирован в `Assets/Editor/VR_Battlegrounds/Weapons/Sights/Core/IronKitMaterials.cs`
  (мушка/целик MX68) — хвост, вне этой задачи.
- Перепаковка (тикет 1099) убрала хром, но стволы «тёмные/плоские» (пользователь, worker, Lobby): альбедо `M_*`
  0,02–0,05 против 0,06–0,14 у `Hands_*`. Подбор в worker: цель 0,10/×3 и 0,07/×2 — «слишком светло»,
  **0,055 / максимум ×1,6 — «так хорошо»** (2026-10-23). Множитель — серый `_BaseColor` материала
  ([tools/apply_base_tint.cs](tools/apply_base_tint.cs)); Mk14, MKR9 и патроны R08 — ×1.
- Стенд сравнения для worker: [tools/compare_stand.cs](tools/compare_stand.cs) (кадры до/после в `reports/stand/`).
