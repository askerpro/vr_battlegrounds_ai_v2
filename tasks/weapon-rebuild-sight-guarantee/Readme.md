# Пересборка оружия не затирает калибровку и разрезанные меши прицелов

2026-10-22. Задача создана командой `task-new`: один агент ведёт её в собственном worktree в ветке `task/weapon-rebuild-sight-guarantee` (схема «задача = агент»).

## Цель

Полная пересборка ствола из пака либо эквивалентна текущему префабу (калибровка, разрезанные меши родного прицела, комплект, хваты, WeaponSystem, баланс, _assetId), либо явно отказывает с понятной причиной без полусобранного префаба; проверено на всём арсенале.

## Этапы

Этапы и области записи — в [plan.json](plan.json). Заготовленный этап `work` пишет только в `tasks/weapon-rebuild-sight-guarantee/**`: перед `begin` объявите нужные пути (`writes`) и перерегистрируйте план (`register`).
