# Единая WeaponSystem: машина состояний оружия

## Цель и мотивация

Всё поведение огнестрела — затвор, патронник, спуск, поза, звук, вибрация, отклик — решает одна машина
состояний `WeaponStateMachine`. Учёт патронов один, в SDK; у каждого канала вывода один исполнитель.
Сейчас за одно и то же отвечают несколько компонентов, и они правят состояние друг за другом. Отсюда были
рассинхрон позы, двойные звуки и сетевая ошибка учёта (исправлена этапом C2).

## Статус

Обновлено 2026-10-09. Владелец — `weapon-system` (Claude, worktree `shotgun-per-shell`).
Влиты этапы B, C, C2 и `drive` (5285ceb7). Этап `waves-f` принят в шлеме и влит 2026-10-09 (5af1c7ef): на машине все стволы
арсенала, кроме револьверов и SDK Shotgun (F5 — развилка, см. Details.md).

- Хост `WeaponSystem`, порт `UxrReadinessLedgerPort`, исполнители позы, звука, вибрации и подсказки.
- Волны F1–F4 (15 стволов + 5 обзорных копий стены лобби) переведены writer `WeaponSystemAuthoring` с readback.
- Звук и вибрация: дефолты по категориям (`WeaponFeedbackDefaults`: автомат, дробовик, пистолет), у ствола только
  оверрайды; подстановка в исполнителях.
- Захват: своя вторая рука не перехватывает огнестрел. Решение — `ManipulationConstraints`
  (выключатель `AllowHandTransfer`, по умолчанию выключен; область — огнестрел), механика — `TwoHandGrabPolicy`
  (решение пользователя 2026-10-09).

До этапа E выстрел решает спуск SDK, упёртый ствол озвучивает `BarrelObstruction`.

## Архитектурное решение

- Чистая машина (`Assets/Scripts/Weapons/Core`, без Unity) → датчики → порт учёта SDK → исполнители позы,
  звука, отклика.
- Учёт SDK не хранит копий физического состояния. Расхождение — `Error`, игра не блокируется.
- Кто использует оружие — `WeaponUseContext.Resolve`: VR-рука или экипировка NPC (`WeaponEquipmentBinding`
  у bots-fix), взаимоисключающие.
- Дефолты звука и вибрации (решение пользователя 2026-10-09): ассет на категорию — автомат, дробовик,
  пистолет; ствол ссылается на ассет своей категории и хранит только оверрайды; дефолт подставляет
  исполнитель, сборщик не копирует. Более точные категории — позже.
