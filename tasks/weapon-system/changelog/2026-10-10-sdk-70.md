# SDK70: политика отдачи корня огнестрела

Дата: 2026-10-10. Задача: `weapon-system`; этап: `use-context-sdk-port`.
Номер: 70, зарезервирован для ключа `use-context`. Независимый SDK-срез аспекта `npc-root-recoil`
согласованного `weapon-use-context@1`; полный этап `use-context` этим не реализован.

Добавлен read-only порт `UltimateXR.Mechanics.Weapons.IUxrFirearmRootRecoilPolicy.AllowsRootRecoil`.
`UxrFirearmWeapon.RootGrabbable_ConstraintsApplied` перечитывает MonoBehaviour-провайдеров
на фактическом grabbable-отправителе через переиспользуемый список. Только разрешение всех
провайдеров допускает штатную отдачу; любой `false` пропускает запись положения/вращения корня.
Выключенные компоненты участвуют в проверке. Без провайдера сохраняется прежний путь SDK.

Выбор root, таймеры отдачи, выпуск снаряда, учёт патронов, звук, вибрация и синхронизация
не изменены. SDK не зависит от игровых binding/resolver. Binding adapter принадлежит bots-fix
и не входит в этот срез. Новые gameplay-тесты и принятый коммит — после проверки пользователем.

Фактическая офлайн-компиляция: Core, UltimateXR (553 исходника), VrBattlegrounds (431) прошли.
Editor (262) остановился на 8 CS0246 в PlayLaunch/Testing/Debug вне SDK-среза;
тестовая сборка из-за остановки не достигнута. Итог existing helper — exit 1.
Новый интерфейс и изменённый consumer включены в UltimateXR response file.
Статический scoped diff: только guard и поле списка в существующем consumer; `diff --check` exit 0.
Полные результаты и границы проверки: `../reports/use-context-sdk-port/implementation.md`,
`compile-escalated.log`, `editor-compiler-full.log`.
Проверка в Unity/шлеме и реального NPC root ещё предстоит; наличие порта не подтверждает стрельбу NPC.
